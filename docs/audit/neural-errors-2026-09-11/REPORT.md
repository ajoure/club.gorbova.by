## Отдельные замечания по доступу — требуют production-проверки

- **S01, высокий приоритет:** legacy `ai-generate-document` читает entity, person,
  signer по переданному ID через service-role без проверки владельца этих объектов.
  RLS клиента не ограничивает такой серверный запрос. Кодовый пробел подтверждён
  (`index.ts:144–183`), но актуальная доступность endpoint и дополнительные runtime-
  ограничения не проверялись. Чужие ID и реальные данные не использовались.
- **S02, высокий приоритет:** `ai-generate-document-package:112–137` доверяет
  декодированному JWT `role=service_role` и маркеру заголовка без проверки подписи
  внутри функции. Безопасность этой ветки зависит от реального gateway verify_jwt.
  Явной секции этой функции в текущем config.toml нет; production-настройка неизвестна.
  Нельзя считать эксплуатацию подтверждённой или безопасной по одному комментарию.
