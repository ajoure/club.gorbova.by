## Ручной разбор

### 1. Gorbova Club — изменения не требуются
- У всех 4 тарифов (BUSINESS, CHAT, FULL, ИДЕОЛОГИЯ) уже есть **свои tariff-scoped** правила `training_content`.
- product-only `club` (чат+канал) даётся всем 4 тарифам — по бизнес-логике это корректно (все тарифы клуба включают телеграм-канал+чат).
- product-only `document_generation` (пакет Идеология) — тоже даётся всем 4 тарифам, корректно.
- **Тех.долг (не критично):** у нескольких тарифов дублируются training_content-правила («full» + «partial» с allow-list, оба с `match_purchase_month=true`). Стоит вычистить дубли отдельной задачей.

### 2. Подоходный налог с физлиц — требуется подтверждение пользователя
- Есть 2 активных тарифа: «2 этапа» и «стандартный».
- Одно product-only training_content правило с `access_mode=full`, `match_purchase_month=false` — открывает весь тренинг всем.
- Если оба тарифа реально дают одинаковый доступ ко всему тренингу — конфигурация корректна.
- Если тарифы должны различаться по объёму контента — правила нужно раскладывать по тарифам.

### 3. Ценный бухгалтер | 2 ступень | 3 поток — требуется подтверждение пользователя
- Есть 2 активных тарифа: «Премиум» и «Стандарт».
- Одно product-only training_content правило с `access_mode=full` — открывает всё обоим тарифам.
- Если тарифы «Стандарт»/«Премиум» должны различаться (обычно да) — правила нужно раскладывать: «Стандарт» получает базовые модули, «Премиум» — все + дополнительные.

## Что дальше
Продукты 2 и 3 не трогаем в этой задаче — только фиксируем находки. Изменения — отдельным утверждённым планом, когда пользователь подтвердит, отличаются ли пакеты по тарифам.
