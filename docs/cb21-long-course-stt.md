# Длинная запись ЦБ: ограниченное распознавание

Статус: реализация для managed Lovable, production dry-run и распознавание ещё не выполнялись.

Практическое занятие длится около 208 минут и не имеет русских субтитров. Обычный скрипт ограничен 30 минутами и остаётся без изменений. Новый `transcribe-long-course.mjs` использует существующие таблицы и RPC: источник/задание до 6 часов, части по 90 секунд, одна попытка на часть. Миграции и развёртывание Edge Functions не нужны.

Перед запуском явно выбираются существующие активные видеоблоки курса. Выключенные исторические разделы не включаются и не получают новые привязки. Наличие русских субтитров, изменение видео, ревизии или выбранного урока останавливает работу.

Dry-run последовательно скачивает диапазоны HLS и декодирует по одной части. В памяти нет полной записи или полного PCM: сохраняются только метаданные плейлиста и хеши, медиа ограничены существующими лимитами range/decode. Манифест не содержит ссылок провайдера, ключей или текста. 208 минут дают 139 частей; точное число берётся из проверенной длительности провайдера.

Запуск только внутри канонической managed-среды Lovable:

```sh
node scripts/sales-knowledge/transcribe-long-course.mjs --managed-lovable \
  --mode dry-run --alias VIDEO_ALIAS --block-ids ACTIVE_BLOCK_ID_1,ACTIVE_BLOCK_ID_2 \
  --report /tmp/long-course-manifest.json
```

После ревизии манифеста и точного SHA256 выполняется не больше 20 выбранных частей за один вызов:

```sh
node scripts/sales-knowledge/transcribe-long-course.mjs --managed-lovable \
  --mode execute --manifest /tmp/long-course-manifest.json \
  --approved-manifest-sha256 REVIEWED_SHA256 --parts 0,1,2 \
  --report /tmp/long-course-batch-1.json
```

Каждый файл отчёта создаётся с `wx` и правами 0600. При возобновлении готовые части сверяются с манифестом и не отправляются повторно на платное распознавание. Неясный результат, незавершённый захват или сбой после захвата удерживает часть; автоматического повторного запроса нет. Финализация разрешена только после всех частей с точными границами и хешами. Полученная расшифровка — `paid_private`, `unreviewed`; скрипт не публикует её клиентам и не добавляет автоматически в базу продавца.

Локальная проверка: 35 тестов нового режима, прежнего STT и импорта проверенных субтитров. Есть сценарии 139 последовательных частей без записи/оплаты, пакетного продолжения, повторного запуска готовых частей, неясного ответа, сбоя после захвата, изменения аудио/ревизии, закрытой привязки, лимита пакета и неполной финализации. Реальные сеть, декодирование и стоимость Lovable требуют отдельного managed dry-run; локальные тесты их не подтверждают.

Конференции №4/5 не входят в этот режим: у них есть субтитры с проблемами качества. Нельзя обходить их проверку запуском полного STT или менять доступность разделов ученикам ради импорта.
