# Точная дата доступа: мобильная прокрутка и период по тарифу

В авторизованном Preview на мобильном viewport подтверждён дефект:
`fieldset` имел высоту 518 px при содержимом 796 px, но не прокручивался;
фокус сдвигал внешний диалог, а GetCourse оказывался под кнопкой сохранения.

Прокрутка перенесена на обычный `div`; `fieldset` остаётся внутри и по-прежнему
блокирует все поля во время запроса. Нижние действия вынесены за область
прокрутки. Права, серверные проверки и тело выдачи не изменены.

Кнопка «Добавить N дней по тарифу» только заполняет точную дату:
подтверждённая текущая граница + N × 86400000 мс. N берётся из настройки
тарифа. Кнопка не выдаёт доступ, не создаёт платёж, не меняет график списаний.
Повторный клик не прибавляет ещё один период. Milliseconds сохраняются.

До отчёта о завершении требуется визуальная проверка уже опубликованной
формы на ПК и мобильном viewport без персональных и платёжных данных.
