# ЦБ21: отдельный тренинг и дата открытия

Последнее решение владельца: **30.09.2026 00:00 Europe/Minsk**. Дополнительные модули, приобретаемые вместе с ЦБ21: **+45 календарных дней = 14.11.2026 00:00 Europe/Minsk**. Сайт `/cb` не менять. Старые тренинги не менять.

## Область изменения

- Продукт `2b7bf6d4-ad8d-46ad-9399-7f96c307c596`, корень `4365e913-36f1-432e-ab16-748c3ca6826a`, поток `b10e15c5-51c3-5df5-ba83-a42416da5902`.
- Каноническая учебная дата — `flows.start_date`. Настройки задержки и ручного режима — `flows.meta.learning_gate`. Сохранение синхронизирует корневой `published_at` и **128** актуальных строк дополнительных предложений. Старые 108 строк каталога остаются в прежнем режиме.
- Настройки доступны в существующей вкладке «Потоки» продукта и форме редактирования корневого тренинга.
- Restrictive RLS скрывает корень/потомков ЦБ21 от людей без собственного действующего доступа к ЦБ21. Старые курсы, клуб и исторические модули не дают такого права.
- До старта закрыты все уроки, блоки, вложения и запись прогресса. После старта сохраняются активность предков, индивидуальные даты уроков, тарифный состав и `require_previous` внутри модуля. **26 выключенных модулей не включаются автоматически**.
- Каталог закрытых уроков возвращает только названия и признаки блокировки, без HTML, описаний и медиа. Серверное время не передаётся учеником.
- Покупатель с действующей подпиской, но без агрегированного entitlement, учитывается без создания новой записи доступа.
- Неоплаченные позиции дополнительных модулей ЦБ21 получают только новые поля расписания. Будущая запись отложенной выдачи сверяется с текущим расписанием независимо от старого снимка.

## Не меняется

Цены, публичная страница `/cb`, тарифные коммерческие сроки `meta.course_access`, документы/снимки оплаченных покупок, подписки, источники доступа, история, клуб, ЦБ20 и старый курс без потока. Четыре отложенные выдачи ЦБ20 вне scope. Учебное открытие не сокращает уже оплаченные сроки.

Общие файлы остаются без переноса: часть контента ссылается на те же публичные объекты, что другие курсы. Этот патч закрывает именно отдельный тренинг и выдачу ссылок из его уроков; он не превращает существующие публичные ссылки на файлы и Kinescope в приватные. Не заявлять обратного.

## Откат

Все изменения схемы и конфигурации применяются одной транзакцией. Ошибка до COMMIT откатывает её целиком. До apply сохранить обезличенные предыдущие конфигурации (flow/root/128 дополнений/7 pending snapshots) через Lovable. `audit_logs` содержит старую/новую учебную конфигурацию каждого изменения. Для отката после COMMIT использовать отдельно проверенную managed migration: восстановить конфигурацию из снимка, снять новые triggers/policies, восстановить прежний `user_has_training_lesson_access` из `private.training_lesson_entitlement_legacy`, затем убрать новые RPC. Автоматический откат не выполняется: он возвращает прежнюю возможность преждевременного просмотра.
