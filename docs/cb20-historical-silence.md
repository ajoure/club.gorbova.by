# Исторический эфир ЦБ20: цифровая тишина до первого субтитра

Для «Конференции 5» проверенный манифест начального пропуска содержит три части: 0–90, 90–180 и 180–183,36 секунды. Первый вызов STT для части 0 вернул 9 символов без букв и остановился в `asr_outcome_uncertain`. Повторять вызов нельзя. Повторный захват с теми же аудиохешами показал, что все PCM-отсчёты частей 0 и 1 равны нулю; в части 2 звук появляется перед первым субтитром.

Миграция `20260925181839_e855ec5f-e169-4c66-9429-5a4266982f0b.sql` добавляет закрытое доказательство цифровой тишины и service-only RPC. Исполнитель заново сверяет исходный манифест и байты WAV; принимает только 16 кГц mono PCM, где каждый отсчёт равен нулю. RPC разрешена только для исторического источника с привязкой к эфиру, частей 0 и 1 и роли владельца. Исходный сомнительный ответ STT части 0 и его хеш сохраняются. Для части 1 сохраняется явный служебный маркер; ни один из этих текстов не входит в итоговую расшифровку после решения `non_speech`. Повторная операция использует записанное доказательство и не меняет данные.

После этого старый `course_gap_claim` может обработать только оставшуюся часть 2. Любой пустой, спорный или неопределённый ответ снова останавливает выполнение без повтора. Расшифровка не публикуется автоматически: перед публикацией нужно отдельное решение по каждой части и проверка, что для обеих частей с доказанной тишиной выбрано `non_speech`. Кампания продаж остаётся OFF/HUMAN_HOLD; уроки, доступы и продажи не меняются.

Фактически STT части 2 (180–183,36 с) вернул один знак без букв. Аудит остался `review_required`, текст и хеш ответа сохранены, повтор запрещён. Миграция `20260925223000_cb20_historical_held_microfragment_review.sql` разрешает закрытую публикацию только после явного решения владельца `non_speech` для этой единственной неопределённой части. Причина решения и исходный хеш сохраняются в приватном ревью. Ни один статус части не переписывается, новые STT-вызовы не производятся; до решения владельца публикация остаётся остановленной.
