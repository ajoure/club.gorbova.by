# Настройки страницы «Спасибо» после анкеты ЦБ

## Статус

Инструкция описывает патч PR #611. До применения managed-конфигурации и
публикации эти поля не доступны на действующей странице.

Read-only проверка 09.10.2026: `predzapiscb21anketathanks` сейчас содержит
HTML-блок с двумя обычными ссылками. Личная переписка использует уже готовую
ссылку Telegram Business. Канал использует общее статичное приглашение.
Раздельных полей для этих адресов в текущем HTML-блоке нет.

## После публикации патча

В разделе «Конструктор сайтов» откройте страницу «Спасибо» и блок
«Бонусы после анкеты»:

1. В «Страница исходной анкеты» выберите страницу предзаписи.
2. В «Анкета на странице» выберите нужную форму. После смены страницы
   форму нужно выбрать заново: прежняя привязка очищается.
3. В «Личная переписка Катерины» вставьте существующую ссылку Telegram
   Business вида `https://t.me/m/…`. Не вставляйте туда приглашение в канал.
4. Сохраните страницу и опубликуйте её в обычном рабочем порядке.

Текст подготовленного сообщения задаётся самой ссылкой Telegram Business:
его меняют в настройках соответствующей ссылки в Telegram. Платформа
не подменяет этот текст и не отправляет сообщение за клиента.

При переносе действующей страницы в новый блок готовую Business-ссылку
нужно скопировать из существующего HTML без изменения адреса. Адрес
получателя не хранится в исходном коде приложения.

## Персональное приглашение в канал

Общее приглашение нельзя вставлять в этот блок. После подтверждения почты,
отправки анкеты и подключения support-бота платформа получает персональную
ссылку для Telegram владельца анкеты. Страница и бот используют один журнал
приглашений. Ссылка бессрочная; право на бесплатный канал не зависит от
платных подписок. Передача ссылки другому Telegram ID не даёт права вступить.

Сам маршрут «анкета → бот → канал» задаётся защищённой конфигурацией
интеграции. Этот редактор страницы не меняет права бота, секреты или
привязки коммерческих каналов. До появления отдельного интерфейса управления
маршрутом его смена остаётся managed-операцией администратора интеграции.

Анкета не выдаёт доступов к урокам или тренингам.
