# Настройки страницы «Спасибо» после анкеты ЦБ

## Статус

Инструкция описывает патч PR #611. До применения managed-конфигурации и
публикации эти поля не доступны на действующей странице.

Read-only проверка 09.10.2026: `predzapiscb21anketathanks` сейчас содержит
HTML-блок с двумя обычными ссылками. Личная переписка использует уже готовую
ссылку Telegram Business. Канал использует общее статичное приглашение.
Раздельных полей для этих адресов в текущем HTML-блоке нет.

Решение пользователя 09.10.2026: две общие бессрочные ссылки на бесплатный
канал — одна для страницы «Спасибо», другая для рассылок. Пересылать их можно.
Персональные приглашения и проверка Telegram ID для вступления не нужны.

## После публикации патча

В разделе «Конструктор сайтов» откройте страницу «Спасибо» и блок
«Бонусы после анкеты»:

1. Выберите страницу исходной анкеты и её форму для связи настроек.
   После смены страницы форму нужно выбрать заново.
2. Укажите название бесплатного канала и ссылку для страницы «Спасибо».
3. В «Личная переписка Катерины» вставьте существующую ссылку Telegram
   Business вида `https://t.me/m/…`. Не вставляйте туда приглашение в канал.
4. Сохраните страницу и опубликуйте её в обычном рабочем порядке.

Текст подготовленного сообщения задаётся самой ссылкой Telegram Business:
его меняют в настройках соответствующей ссылки в Telegram. Платформа
не подменяет этот текст и не отправляет сообщение за клиента.

При переносе действующей страницы готовую Business-ссылку нужно скопировать
из существующего HTML без изменения адреса. Ссылки и название канала
не задаются константами в исходном коде приложения.

## Рассылки

В шаблоне Telegram-рассылки задайте вторую общую ссылку на канал в поле URL
кнопки. Её адрес независим от настройки страницы «Спасибо». В событийном
условии выберите исходную анкету и событие «Анкета сохранена», затем нужную
задержку (0 — сразу). Персональные приглашения не создаются.

Подключение support-бота выполняется после подтверждения email, до сохранения
анкеты и перехода на «Спасибо». Уже подтверждённая привязка используется
повторно без нового подключения. Иначе пользователь открывает бота и нажимает
«Старт», платформа получает Telegram ID и подтверждает связь с аккаунтом.
Для стороннего входа по пересланной общей ссылке в бесплатный канал наличие
аккаунта или привязки не требуется.

Бесплатный канал должен быть отделён от коммерческих каналов клуба:
окончание подписки не является основанием для исключения из него.
Изменение конфигурации самого бота и отделение каналов выполняет администратор
интеграции по managed-процедуре, редактор страницы не меняет секреты или права.

Анкета не выдаёт доступов к урокам или тренингам.

## Статистика источников

В разделе «Анкеты и данные» откройте вкладку «Анкета предзаписи».
Выберите анкету и даты (по времени Минска, включая последний день).
Таблица показывает первый источник/UTM, переходы, посетителей, сохранённые
анкеты и контакты. Максимальный период одного запроса — 366 дней.

Этот экран имеет отдельное право `forms-hub / preregistration-stats`.
Нулевые показатели не заменяют ошибку загрузки. Контакты без подтверждённого
исхода регистрации отмечаются как неразмеченные и не считаются новыми
по дате создания карточки. Запись исхода при OTP ещё должна быть подключена
до приёмки всей функции и публикации.
