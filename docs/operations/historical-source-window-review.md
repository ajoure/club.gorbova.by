# Проверка границы зависимого доступа перед исполнением

Обнаруженный дефект: RLS/RPC проверяет `entitlements.status/expires_at`, но не
фактический источник клуба. `revoke_access` заканчивает окно подписки сейчас и
отзывает entitlement клуба, однако исторические secondary entitlements остаются
активными до своего прежнего срока. Данных о реальном списании этот дефект не даёт.

Проверяемый контракт исправления:

| Сценарий | История | Доступ через клуб |
| --- | --- | --- |
| Только исторический paid факт | Остаётся | Не появляется |
| Оплаченный Business, текущее конечное окно | Остаётся | Только купленный состав |
| Отмена автопродления, окно ещё оплачено | Остаётся | До конца оплаченного окна |
| Фактический revoke_access, конец окна сейчас | Остаётся | Прекращается сейчас |
| Конец окна в точности равен now | Остаётся | Закрыт, без дополнительных grace-часов |
| Истёкший источник + другое действующее основание | Остаётся | Сохраняется в пределах другого основания |
| Самостоятельная покупка/ручной доступ к продукту | Остаётся | Собственное основание не урезается |
| Приостановленный/удалённый/неоплаченный заказ | Не считать новым paid источником | Не выдавать через него |

Перед миграцией проверить фактические определения `user_has_training_lesson_access`,
все permissive SELECT/ALL policies `training_lessons/lesson_blocks/entitlements`,
и 49 secondary с иной lineage. Один исправленный permissive policy не закрывает
обход через другой. SECURITY DEFINER функция не полагается на RLS entitlements.

Нельзя считать отмену автопродления автоматическим отзывом уже оплаченного срока.
При нескольких основаниях нельзя обрезать агрегированный entitlement только потому,
что закончилась одна подписка. Не переносить семантику grace клуба на исторические
продукты без отдельного основания. Существующая metadata `historical_tariff_id`
сама по себе не доказывает ограничения фактического backend доступа.

Миграция/execute остаются неготовыми до свежего аудита policies/source lineage,
проверок этих сценариев в изолированной БД и безопасного read-back production.
