# Выбранные закрытые уроки как источники знаний

Статус: подготовка аудита пропусков, не публикация итоговой расшифровки.
Доступы учеников и активность уроков/модулей не меняются.

Существующий managed CLI `audit-caption-gaps.mjs` принимает в dry-run
`--reviewed-block-ids <UUID,UUID>` и, только с этим явным выбором,
`--allow-cue-order-review`. Обычный запуск сохраняет строгий запрет на
выключенные уроки. Явный выбор доступен только существующему super_admin;
каждый блок должен принадлежать проверенному alias и допустимому продукту.

Манифест фиксирует точный выбор, признаки активности, ревизию видео,
хеш исходного VTT, хеш нормализованного VTT и неизменный набор реплик.
Сортировка разрешена только в прежних пределах reviewed-captions:
до3 инверсий,30с обратного шага,32 перемещённых позиций, без дублей.
Все остальные замечания остаются блокирующими, кроме допустимого long_gap.
Исходный VTT сохраняется в audit.raw_vtt байт в байт; сортировка применяется
только при анализе. Нормализованный текст не попадает в публичный отчёт.

Execute повторно читает выбранные блоки и исходник перед записями и каждой
частью. Изменение активности, привязки, VTT или ревизии прекращает операцию.
Источники и связи — существующие course сущности; результаты private/unreviewed.
Для нового режима захват аудио учитывает AAC tail; старые audit manifests
сохраняют прежние диапазоны и хеши.

Сохранение итоговой расшифровки требует следующего отдельного изменения:
существующий course_gap_publish_reviewed рассчитан на семь частей с
продолжением после uncertain, а у конференций18 №4/5 ожидаются две части.
Этот патч не обходит публикационный guard и не объявляет базу знаний готовой.
Перед production execute обязательны dry-run, проверка точного манифеста,
контроль счётчиков и read-back. Платные повторы после неизвестного исхода
запрещены существующим журналом попыток.
