# Реферальная программа: соответствие КБЗ

В GitHub реализованы правила из `КБЗ Реферальная программа.pdf`:

- единая схема, ступени 10 / 20 / далее и схема «Club — первый платёж»;
- Global/Gorbova Club — 30% только от первого разового платежа приглашённого;
- внутренние баллы в BYN для образовательных продуктов, с запретом для Club и открытых автоподписок;
- использование баллов спрашивается на оплате разового продукта и конечной рассрочки;
- максимум наличной выплаты 40%, минимум заявки 1 000 BYN;
- персональные короткие ссылки на бесплатные программы;
- полный список приглашённых и продаж без UI-среза в пять записей;
- Telegram-уведомления о регистрации и покупке/начислении.

Остаётся применить миграцию и Edge Function в Lovable Cloud, затем выполнить живой сценарий: новая регистрация по `https://gorbova.by/r/CODE`, разовый платёж, Club/подписка, конечная рассрочка, резерв/освобождение баллов и доставка Telegram. Автопродление намеренно не создаёт комиссию и не получает скидку при создании подписки.
