## Изменение поведения

Обе страницы `/cb` и `/course-accountant` используют один ID продукта,
живые тарифы/офферы и UniversalPricingSection. На альтернативной странице
устранён прежний обработчик, который только показывал toast вместо оплаты.
Все четыре способа на каждом тарифе — карта, банк, два платежа, счёт юрлицу —
передают точный выбранный оффер в существующие checkout-диалоги. Основная
показываемая цена берётся из платёжного оффера раньше устаревшего display override.

Новые тарифы включают `meta.course_access` с календарными месяцами от даты
окончания курса. Канонический grant, 3DS writer и checkout/recovery windows
используют эту политику. Повторный платёж не прибавляет ещё один период.
3DS writer не выводит график платежей из фиксированного окончания доступа.
Resolver выбирает правила отдельно для каждого корневого тренинга, чтобы
бонусное правило не вытесняло основной курс из-за порядка строк.

Три бонусных модуля исключаются только из нового тарифа Бухгалтер. Семь
правил 30-дневных бонусов копируются без изменения их сроков и целей.

## Бесплатная предзапись

`/predzapiscb20` и `/predzapiscb20anketa` содержат формы сбора заявок на
отдельный бесплатный продукт предзаписи без платёжных офферов. Цен и дат
на этих страницах нет. Они не являются кнопками оплаты курса; переводить
их на платный продукт без отдельной проверки выдачи доступа нельзя.
`/cb20predzapis` содержит ссылки на эти формы; реального Tilda checkout
или товарных атрибутов не найдено. Черновики страниц не публикуются.
