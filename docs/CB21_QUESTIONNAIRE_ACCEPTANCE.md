# Цель и критерии приёмки предзаписи ЦБ21

Обновлено по прямым решениям пользователя 09.10.2026. Этот документ уточняет
активную цель: прежнее обещание бонусного урока отменено пользователем.

## Цель

Реализовать и опубликовать путь предзаписи: анкета до авторизации,
черновик и однократная отправка, шестизначное подтверждение email в том же
окне, проверка/привязка support-бота ДО перехода на страницу «Спасибо»,
корректная связь анкеты и всей истории с контактом и продуктом предзаписи,
две настраиваемые кнопки на странице «Спасибо», событийные уведомления без
дублей и статистика переходов/анкет/регистраций по источникам и UTM.
Существующие пароли, покупки, доступы и коммерческие чаты сохраняются.

## Путь клиента

1. Переход на `/predzapiscb21anketa` с сохранением источника/UTM.
2. Контакты и вопросы на одной странице до входа; локальный черновик при
   перезагрузке. Для отправки требуется действительное согласие.
3. Email подтверждается шестизначным кодом здесь же; создание пароля не
   требуется. Существующий клиент используется без дублирования аккаунта.
4. В этом же процессе проверяется действительная привязка к primary
   support-боту. Если она уже есть, повторного подключения нет. Иначе
   пользователь открывает бота и нажимает «Старт»; платформа получает TG ID,
   подтверждает связь с текущим аккаунтом. Нельзя доверять введённому вручную
   нику или Telegram ID вместо подтверждённой привязки.
5. После проверки связи с ботом анкета сохраняется однократно в карточке
   контакта, сохраняются все ответы/история и связь с продуктом предзаписи.
6. Переход на `/predzapiscb21anketathanks` только после успешного сохранения.
   Две основные кнопки: общая бессрочная ссылка на бесплатный канал и
   существующая Telegram Business ссылка личной переписки Катерины.
7. Подготовленный текст сообщения задаётся существующей Business-ссылкой,
   отправку подтверждает сам клиент в Telegram.

## Канал и настройки

- Общие ссылки можно пересылать, без индивидуальных приглашений/TG-ID gate.
- Ссылка для страницы «Спасибо» и ссылка для рассылок — разные, бессрочные.
- Бесплатный канал не зависит от клуба; окончание подписки не исключает
  участника из этого канала.
- Ни одного урока или тренинга анкета не открывает.
- Ссылки/название канала задаются в настройках, не константами кода.
- Готовую Business-ссылку сохраняем без изменения адреса. Текст управляется
  Telegram Business, он не хардкодится платформой.

## Статистика и доказательства

- Отдельный пункт «Анкета предзаписи»: переходы, отправленные анкеты,
  регистрации новых и входы существующих по источнику/UTM.
- Поддержать десять пресетов источника и обычные произвольные UTM-ссылки.
- Счётчики без дублей, проверка прав на просмотр, отсутствие PII в агрегатах.
- GitHub checks, managed Lovable review/execute с точным SHA и счётчиками,
  read-back, согласованный реальный runtime sample.
- Публикация подтверждается URL/версией и двумя проверенными скриншотами:
  ПК и мобильный viewport. Preview/сборка/HTTP 200 не заменяют это доказательство.

## Текущий статус

Цель активна. Документ — критерии и порядок, не свидетельство публикации.
Перенос обязательной привязки бота перед «Спасибо» требует изменения UI
и серверной проверки; нельзя ограничиться перестановкой текста.
