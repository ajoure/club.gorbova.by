# Требования к оформлению корпоративных документов

Спецификация форматирования DOCX-шаблонов для модуля «Корпоративные документы» (годовое собрание ООО/ОДО, решение единственного участника).

## Правовая основа

- Инструкция по делопроизводству в государственных органах, иных организациях (утв. Постановлением Министерства юстиции Республики Беларусь от 19.01.2009 № 4)
- Закон Республики Беларусь «О хозяйственных обществах»
- СТБ 6.38-2004

## 1. Поля страницы

| Поле | Размер (мм) | DXA |
|------|-------------|-----|
| Верхнее | 20 | 1134 |
| Нижнее | 20 | 1134 |
| Левое | 30 | 1701 |
| Правое | 10 | 567 |

Формат бумаги: A4 (210 × 297 мм / 11906 × 16838 DXA).

## 2. Обязательные реквизиты документа

Для организационно-распорядительных документов (приказ, решение, протокол):

1. **Наименование организации** — полное, в соответствии с учредительными документами
2. **Название вида документа** — ПРОПИСНЫМИ БУКВАМИ (ПРОТОКОЛ, РЕШЕНИЕ, ПРИКАЗ, ИЗВЕЩЕНИЕ)
3. **Дата документа** — в формате ДД.ММ.ГГГГ
4. **Регистрационный индекс** — порядковый номер в пределах календарного года
5. **Место составления или издания** — город (г. Минск)
6. **Текст документа**
7. **Подпись** — наименование должности, личная подпись, расшифровка подписи

## 3. Правила для протокола

- Название вида документа: **ПРОТОКОЛ** (прописными)
- Нумерация: сквозная в пределах календарного года
- Обязательные разделы:
  - **СЛУШАЛИ:** — ФИО докладчика, краткое содержание
  - **ВЫСТУПИЛИ:** — ФИО, краткое содержание (если были выступления)
  - **РЕШИЛИ:** (или **ПОСТАНОВИЛИ:**) — текст принятого решения
- Для каждого вопроса повестки: отдельный блок СЛУШАЛИ / ВЫСТУПИЛИ / РЕШИЛИ
- Результаты голосования: «за» — N, «против» — N, «воздержался» — N
- Подписи: Председатель / Секретарь

## 4. Правила для приказа / решения

- Название вида документа: **ПРИКАЗ** / **РЕШЕНИЕ** (прописными)
- Нумерация: сквозная в пределах календарного года
- Структура: констатирующая часть + распорядительная часть (ПРИКАЗЫВАЮ: / РЕШИЛ:)
- Подпись: должность лица, подписавшего документ

## 5. Правила для извещения

- Название вида документа: **ИЗВЕЩЕНИЕ**
- Обязательные элементы:
  - кому направлено (ФИО участника или наименование организации-участника)
  - дата, время и место проведения собрания
  - повестка дня
  - порядок ознакомления с материалами
- Дата направления извещения

## 6. Правила для решения единственного участника

- Название: **РЕШЕНИЕ** единственного участника
- НЕ «протокол», НЕ «собрание»
- Подпись: единственный участник (не «Председатель»)
- Указание на полноту полномочий в соответствии с уставом

## 7. Терминология

| Правильно | Неправильно |
|-----------|-------------|
| Участники | Учредители (для действующего общества) |
| Решение единственного участника | Протокол единственного участника |
| Общее собрание участников | Собрание учредителей |
| Лица, имеющие право на участие | Присутствующие лица |

## 8. Шрифт и форматирование

- Шрифт: Times New Roman, 14 пт (для основного текста)
- Межстрочный интервал: одинарный или 1.5
- Абзацный отступ: 12.5 мм (первая строка)
- Выравнивание основного текста: по ширине
- Выравнивание названия вида документа: по центру
- Выравнивание реквизитов подписи: правый край для расшифровки
