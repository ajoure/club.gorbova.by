# Разделение проверки интерфейса и серверного платёжного теста

В `main` 6c2d6afd проверка `tsc -p tsconfig.app.json --noEmit` давала
15 диагностик: три серверных платёжных теста из `src/test` втягивали Deno
адаптеры в браузерный TypeScript-проект. Обычная сборка Vite этого не проверяет.

Тесты канонического восстановления и точного окна доступа перенесены в
`tests/edge` без изменения сценариев. Vitest явно включает этот каталог:
тесты не исключены из проверок.
Браузерная проверка продолжает проверять весь `src`, включая остальные тесты,
без подавления ошибок, ambient-заглушек Deno или изменения платёжного runtime.
В release gate добавлена явная проверка типов приложения.

Проверки: полный Vitest с тем же числом сценариев, TypeScript приложения,
production build, контракт Edge Functions; серверный граф проверяется Deno
в серверной среде отдельно. Этот патч не меняет доступы, сроки, суммы,
авторизацию, данные или провайдера. Publish и восстановление данных требуют
собственных ранее согласованных проверок.
