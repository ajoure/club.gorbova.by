# Продолжение после полученного ответа на другом языке

Gap-аудит сохраняет наблюдения распознавателя отдельно от учебного текста.
Первая часть уже получила непустой ответ без кириллицы и была удержана.
Этот ограниченный режим собирает первые результаты только оставшихся частей
1–6. Он сохраняет первую часть целиком, включая status, attempts, error и текст.
Audit остаётся `review_required/paid_private/unreviewed`.

Новые таблицы содержат отдельный факт разрешения продолжения с полным снимком
удержанной части и неизменным контекстом audit, а также аннотации результатов.
`cyrillic_present` / `no_cyrillic` описывает алфавит, а не достоверность речи или
точное определение языка. `collected` означает завершённый сбор шести ответов;
оно не снимает `long_gap` и не разрешает использование реплик для продаж.

Новые RPC service-only / SECURITY INVOKER. Begin допускается только владельцу
исходного audit и только при непустом сохранённом non-Cyrillic ответе part0.
Claim исключает part0, допускает только pending/attempts0, сериализует вызовы,
проверяет неизменность снимков и блокирует продолжение при новом uncertain.
Истёкшая аренда не создаёт второй попытки. Finish оборачивает прежний RPC,
добавляя проверяемую аннотацию; прежние таблицы и функции не переписываются.

## Порядок

1. GitHub review / checks / merge. Только затем canonical Lovable применяет
   новую continuation-миграцию один раз и проверяет RLS/ACL/инварианты.
2. Managed dry-run `continue-caption-gaps.mjs --managed-lovable --mode dry-run
   --original-manifest <original-file> --audit-id <id>
   --held-text-sha256 <held-hash> --report <new-private-file>`.
   Заново проверяются исходный VTT, provider/player, все семь аудиофрагментов,
   привязки и сохранённые границы. Ноль записей/STT. В отчёте нет ASR-текста,
   приватных ссылок, ключей или claim-token.
3. Одобрить SHA256 нового continuation-манифеста; execute с `--manifest`,
   `--approved-manifest-sha256`, новым приватным `--report`. Максимум шесть
   первых вызовов; любое расхождение источника/снимков останавливает выполнение.
4. Новый provider error, пустой ответ, timeout/429/5xx → uncertain и STOP.
   Непустой ответ другого алфавита хранится как unreviewed ASR evidence.
5. Read-back всех текстовых/аудиохешей, алфавитных флагов, attempts и снимка
   part0; точный replay должен дать ноль вызовов и ноль новых строк.

Секреты берутся только из прежнего managed-окружения, actor — подтверждённый
владелец. Никакого SQL reset, повторного распознавания part0, сборки полного
course transcript, изменения прежних 59 текстов или активации бота.
