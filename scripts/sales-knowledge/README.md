# Подготовка знаний и правил помощника без production

Локальный инструмент обрабатывает **метаданные** нормализованной выгрузки,
не подключается к production и не вызывает распознавание. Подготовлен для
первого этапа базы знаний продаж; это не готовый импорт или обученный бот.

Отдельно подготовлен [импорт существующих субтитров основного курса и
20-го потока](COURSE_IMPORT.md) в закрытое хранилище. Он запускается только
в канонической managed-среде Lovable после ревизии, использует реальные
данные и не покупает повторную расшифровку. Команды ниже остаются offline.

```sh
node scripts/sales-knowledge/plan-transcriptions.mjs /private/snapshot.json /private/new-plan.json
node --test scripts/sales-knowledge/plan-transcriptions.test.mjs
```

Вход schema_version=1: captured_at, complete, expected_lesson_count,
selected_product_ids и lessons. Урок содержит id, product_ids,
mapping_verified, media_inventory_complete, videos. Для урока без видео
нужен non_video_content_verified. Видео: source_id, source_revision,
audio_status, duration_ms и необязательный transcript с status, has_text,
source_revision, coverage_verified. Передавать полные тексты и ссылки не нужно.

Выгрузка составляется только после read-only проверки канонического источника.
Связь урока с продуктом должна учитывать модуль, родителей и существующие
правила доступа; mapping_verified нельзя ставить по совпадению названия.
Видео ищутся и в training_lessons.video_url, и в lesson_blocks, включая
вложенные блоки. Один источник может встречаться в нескольких уроках.
source_id — подтверждённый ID видео провайдера, не URL; source_revision —
проверенная версия дорожки/хеш. coverage_verified означает проверенную
полноту всех частей, а не просто status=ready.

План повторно использует только полный текст актуального источника,
дедуплицирует видео между уроками, считает объём нового аудио и останавливает
весь пакет при неполной выгрузке, конфликте источников или неизвестной связи.
Любой результат остаётся execution_authorized=false: исполнение проходит
отдельную проверку и существующий контур расшифровки платформы.

Коды завершения: 0 — план для проверки, 2 — план содержит блокирующие пробелы,
1 — вход/путь/формат не обработан. Выход создаётся новым файлом с правами 0600;
существующий файл не перезаписывается. В stdout только агрегированные счётчики.
Вывод не содержит исходные тексты, названия уроков или ссылки скачивания.

Реальные входы, выходы, отзывы и расшифровки хранятся вне публичного GitHub.
Никакого автоматического утверждения описаний, отправки клиентам или обучения
модели этот инструмент не выполняет.

## Реализованные независимые модули

| Модуль | Результат |
|---|---|
| `lib/inventory.mjs` | Реестр видео из уроков, вложенных блоков и HTML-контейнеров; проверка дерева модулей и подтверждённых связей продукта; точные UUID/короткие ID Kinescope |
| `plan-transcriptions.mjs` | Полный проверяемый план: повторное использование текста, дедупликация, неизвестные источники и объём аудио |
| `lib/transcript.mjs` | Окна аудио, сборка всех частей в закрытый текст, контроль версии и покрытия, ограниченный пакет с журналом прежних попыток |
| `lib/knowledge.mjs` | Проверка редакций описаний/отзывов и поиск только по утверждённым знаниям разрешённого продукта/тарифа |
| `lib/client-context.mjs` | Контекст подтверждённых покупок, доступов, вебинарной активности и явных предпочтений; неизвестное не становится фактом |
| `lib/dialogue-policy.mjs` | Решение о допустимости ответа и переходы ожидания/передачи человеку; независимы от модели |
| `offline.mjs` | Запуск этих операций над локальными JSON-файлами, без сетевых запросов |

Все тесты включены в release-quality-gate:

```sh
node --test scripts/sales-knowledge/*.test.mjs
node scripts/sales-knowledge/offline.mjs inventory /private/export.json /private/inventory.json
node scripts/sales-knowledge/offline.mjs assemble /private/parts.json /private/transcript.json
node scripts/sales-knowledge/offline.mjs compile /private/reviewed-facts.json /private/sales.json
node scripts/sales-knowledge/offline.mjs retrieve /private/query.json /private/context.json
```

Также поддерживаются `batch`, `context`, `policy`. Выход всегда новый файл
с правами 0600. Команда `assemble` создаёт **полный закрытый текст**: её
результат нельзя отдавать продавцу. Остальные команды не получают
разрешение на production-запись или отправку из факта успешного завершения.

Подробный [контракт интеграции](INTEGRATION.md) описывает обязательные поля,
границы доверия и оставшиеся проверки. Публичные тесты используют только
синтетические данные, не материалы реального обучения.
