Эти 12 SQL-файлов содержат только идемпотентные `INSERT` в временную схему
`asset_classifier_import`. Они не являются Supabase migrations и не изменяют
рабочие таблицы напрямую.

Порядок production-выпуска:

   `20260730002000_asset_classifier_resolution_161_import_buffer.sql`.
2. Выполнить `resolution_161_batch_01.sql` … `resolution_161_batch_12.sql`

3. Проверить: 2 349 строк, 12 батчей, 2 349 уникальных `node->>'id'`,
   checksum `ac7e28c93b6b3d1f029cec22593157d1624f9de9c7ffee1a811bd60e743b5f4b`
   и наличие `code-70034`.

   `20260730002001_asset_classifier_resolution_161_finalize_from_buffer.sql`.

временную схему вместе с выданными на неё правами. При остановке до финального
шага карточка постановления остаётся неопубликованной.
