# Вебинар 24.10: одна форма и настройки сообщений

Выпуск `web2410-v2` продолжает существующую регистрацию без изменения Auth,
RPC, Edge Functions, покупок и доступов. Анкета ЦБ21 и её Thanks не меняются.

- HTML Никиты сохраняет секции, адаптивность и CTA, но не собирает контакты:
  кнопка открывает один канонический `FormSection` в `SiteRegistrationDialog`.
- Телефон: существующий `PhoneInput`, только webinar-ветка формы. Общая
  серверная проверка международного формата остаётся прежней.
- Thanks: opt-in `design=webinar` существующего `questionnaire_bonuses`.
  `designer_html` подготовлен из уже адаптированного для sandbox исходника
  Никиты; две кнопки получают валидированные CMS-ссылки из прежних полей.
- В настройках страницы — переход в существующий редактор рассылок с
  проверенными page/block ID, просмотр правил этой страницы и переход в
  существующие approval, pause/resume и журнал.
- Сохранение site-form события: `draft/event/pending_approval`. Включение
  задаёт новый `submissions_from` и требует отдельного одобрения.
  Редактирование снова выключает правило. Старые регистрации не догоняются.
- Существующий manual-draft вебинара не превращается в авторассылку.
  CMS-выпуск не создаёт и не меняет шаблоны.
- Email-тест использует существующий административный тест на указанный
  адрес; это не новый серверный self-only endpoint. Реальная отправка требует
  разрешения владельца на адрес и текст. Telegram-тест — прежний self-test.

## Проверки и managed apply

`node build-release.mjs` создаёт детерминированные SQL-артефакты.
`release-managed-dry-run.sql` только проверяет baseline, ничего не обновляет.
`release-managed-apply.sql` атомарно обновляет ровно две существующие страницы.
Повторный запуск строго проверяет результат и делает ноль записей.
Любое изменение полей формы, ссылок, защищённых ЦБ21, тарифа, SEO/темы или
версии исходных страниц останавливает применение. Managed SQL исполняет
только Lovable Cloud из точного merged SHA через проверенный immutable fetch.

После CI и readback: обычный Publish, проверка версии `web2410-v2`, отдельные
скриншоты ПК и mobile для формы, Thanks и настроек. Отправки планировщика,
реальные сообщения и новые контакты не используются как скрытый smoke.
