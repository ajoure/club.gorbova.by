- **Canonical:** Lovable Cloud agent-deploy (internal, via Lovable platform).
- **Constraint:** webhook functions (`stripe-webhook`, `bepaid-webhook`, `telegram-webhook`, `payment-methods-webhook`, `auth-email-hook`, `instagram-webhook`, `getcourse-webhook`, `amocrm-webhook`) **must not** be redeployed via agent-deploy without an immediate post-deploy runtime smoke (`verify-webhook-runtime.yml`), because the platform has been observed to ignore `verify_jwt = false` and inject a JWT wall (D2/D2-BIS regression).
