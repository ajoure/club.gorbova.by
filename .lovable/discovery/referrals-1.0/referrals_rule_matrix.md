# План: правила MVP

| Правило | Рекомендуемое значение |
|---|---|
| Атрибуция | first valid referrer wins |
| Existing contact | только ручная привязка админом |
| Комиссия | 10% (`1000` bps) от фактически оплаченной суммы |
| Повторные покупки | отдельные коммерческие покупки да; rebill нет |
| Возвратный период | product rule, иначе program default |
| Бесплатный/test/lead | нет комиссии |
| Split | только исходный parent order |
| Рассрочка | одна комиссия после полной оплаты |
| Self-referral | запрещён |

Пункты «повторные покупки» и «60/40 points» требуют явного бизнес-подтверждения.
