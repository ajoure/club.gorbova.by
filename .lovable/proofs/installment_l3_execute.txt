### L3.4 — Verification (запускается после первой реальной оплаты по installment-ссылке)
SQL:
```
SELECT
  o.id as order_id,
  o.meta->>'installment_count' as meta_count,
  o.meta->>'installment_per_payment_amount_byn' as meta_per_payment,
  o.meta->>'installment_total_amount_byn' as meta_total,
  COUNT(ip.*) as actual_count,
  SUM(ip.amount) as actual_sum,
  MIN(ip.amount) as min_amt,
  MAX(ip.amount) as max_amt
FROM orders_v2 o
LEFT JOIN installment_payments ip ON ip.order_id = o.id
WHERE (o.meta->>'installment_count')::int >= 2
GROUP BY o.id, o.meta
ORDER BY o.created_at DESC
LIMIT 5;
```
Контракт пройден, если:
- meta_count = actual_count
- meta_per_payment = min_amt = max_amt
- meta_total = actual_sum
