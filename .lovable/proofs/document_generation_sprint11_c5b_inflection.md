# Sprint 11 — C5-B: безопасное склонение (RU inflection)

Дата: 2026-05-08
Версия резолвера: `strict-1.3.0-c5b`

## Что добавлено

1. **Модуль `supabase/functions/_shared/ru-inflection.ts`** — компактный
   безопасный склонятель. Контракт:

   ```ts
   inflectRu(input: string, case: RuCase): {
     value: string;          // итог (или исходник, если applied=false)
     applied: boolean;       // true только если безопасно склонено
     reason?: string;        // 'unknown_cyrillic_token' | 'no_inflectable_token' | ...
     per_token?: [...]       // отладка: какое слово какое правило получило
   }
   ```

2. **Принцип безопасности — главное правило.**
   Если хотя бы одно кириллическое слово не подпадает ни под одно правило
   (`unknown_cyrillic_token`), весь результат отбрасывается → возвращается
   исходная строка с `applied=false`. Это предотвращает искажение
   незнакомых названий.

3. **Что НЕ склоняется (всегда сохраняется как есть):**
   - аббревиатуры орг.-правовых форм: `ООО ЗАО ОДО ИП АО ПАО ОАО ТОО НКО СП ЧП КФХ ИЧП УП РУП ГУП ФЛП СПД ОЮЛ ЧУП НПФ ФГУП МУП`;
   - всё в кавычках `"..." «...» “...”`;
   - содержимое скобок `(...)`;
   - латиница;
   - слова заглавными буквами (вероятная аббревиатура).

4. **Поддерживаемые морфо-классы (приоритет сверху вниз):**
   - женское отчество `-овна/-евна/-ична/-инична`;
   - женская фамилия `-ова/-ева/-ина/-ына`, `-ская/-цкая`;
   - мужское отчество `-ович/-евич/-ьич/-ич`;
   - мужская фамилия `-ов/-ев/-ин/-ын`, `-ский/-цкий/-ской/-цкой`;
   - мужское имя на `-й` (Сергей, Николай);
   - адъективное существительное на `-щий/-ший/-чий` (управляющий);
   - прилагательное м.р. `-ый/-ий/-ой` (генеральный, главный, индивидуальный);
   - существительное м.р. на `-ь` (предприниматель, руководитель, учитель);
   - существительное м.р. на согласную (директор, Иван, Федорчук).
   - словарь типичных должностей и эпитетов для приоритета.

5. **Интеграция в `canonical-document-generate-strict`** (loop 389–462):
   - Сначала применяется `format=words/text` (C5-A).
   - Затем, если есть `case=...`, на полученную строку вызывается `inflectRu`.
   - Падеж разрешён: для текстовых типов / enum / unknown data_type
     **или** если `format=words` уже применён.
   - Для number/money/date/datetime/boolean без `format=words` — падеж
     не применяется, warning `case_on_non_text_field_without_words`.
   - При успехе: `variants[].case_applied = true`,
     warning `case_modifier_not_applied` снимается.
   - При неуспехе: `case_applied=false`, `case_reason` заполняется,
     warning остаётся.

## Примеры (ожидаемое поведение)

| Вход | Падеж | Результат | applied |
|------|-------|-----------|---------|
| `Сергей Федорчук` | genitive | `Сергея Федорчука` | true |
| `Федорчук Сергей Валерьевич` | genitive | `Федорчука Сергея Валерьевича` | true |
| `директор` | genitive / dative / instrumental | `директора` / `директору` / `директором` | true |
| `генеральный директор` | genitive | `генерального директора` | true |
| `управляющий` | genitive / dative | `управляющего` / `управляющему` | true |
| `индивидуальный предприниматель Иванов Иван Иванович` | genitive | `индивидуального предпринимателя Иванова Ивана Ивановича` | true |
| `ООО "АЖУР инкам"` | genitive | `ООО "АЖУР инкам"` (без изменений) | **false** — `АЖУР` skip (caps), `"АЖУР инкам"` skip (quoted), окружения нет → `no_inflectable_token` |
| `Анна Иванова` | genitive | `Анны Ивановой` | true (hint=f по фамилии) |
| `Мария Петровна` | dative | `Марии Петровне` | true |

### money words + case
- Поле money=250.00, BYN, `{{field:FLD-1|format=words|case=genitive}}`:
  - C5-A → `двести пятьдесят белорусских рублей 00 копеек`;
  - C5-B → `inflectRu` встретит «белорусских», «рублей», «копеек» — слова
    не подпадают под текущие правила (множ.число) → `applied=false`,
    итог остаётся прописью без склонения, warning `case_modifier_not_applied`
    с reason `unknown_cyrillic_token`. Это безопасный fallback.
