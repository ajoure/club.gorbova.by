### 4.2. Что происходит при клике

- **Главный бухгалтер / Бизнес-леди** (`bank_installment`): открывается `LeadRequestDialog` → просит email → OTP-подтверждение → **только затем** отрисовывает `<a href="{bankLinkUrl}" target="_blank">` (см. `src/components/lead/LeadRequestDialog.tsx:345-348`). Источник `bankLinkUrl` = `readBankInstallmentMeta(offer).external_link`, то есть тот же legacy `pay.rrllc.ru/katerina-gorbova-credit`. Никаких других сетевых вызовов.
- **Бухгалтер** (`pay_now`, button_label «Оплатить в рассрочку от банка»): открывается `PaymentDialog` с заголовком **«Бухгалтер — 0 BYN»** — это оффер типа `pay_now` с amount=0, а не `bank_installment`. См. §Anomalies.

Headless-скрипт не завершает OTP, поэтому финальный переход на `pay.rrllc.ru` не кликнут вживую. Однако:
1. код `LeadRequestDialog.tsx` рендерит `<a href={bankLinkUrl}>` статически, без edge-function вызовов;
2. network-логи содержат 0 запросов к любым РР-путям на всех этапах.

Итог: **legacy flow не сломан**. Кнопка `bank_installment` доводит клиента до внешней ссылки `pay.rrllc.ru/katerina-gorbova-credit` через existing lead-verify + external anchor, без единого нового runtime-вызова.

## 6. Anomalies (не фиксим в Sprint 2.1, но фиксируем для будущих спринтов)

1. **«Бухгалтер» — кнопка «Оплатить в рассрочку от банка» на самом деле `pay_now` с amount=0.00.** При клике открывает `PaymentDialog` с суммой 0 BYN — это нерабочий flow. Нужно либо (а) конвертировать в `bank_installment`-оффер с тем же `external_link`, либо (б) удалить кнопку, либо (в) выставить реальный amount с корректным флоу. Отдельный тикет — не Sprint 3.
2. **Разница между `tariffs.original_price`/публичной ценой (1950/2450/3350) и `tariff_offers.amount` у `pay_now` (1650/1950/2650).** Дельта ровно 300 BYN на каждый тариф. Похоже на original_price vs discount. Требует отдельной сверки source-of-truth для отображения цены (не в scope Sprint 2.1).
3. **`meta.bank_installment.installment_provider` / `rr_mode` / `currency` не сохранены в legacy-записях.** Sprint 3 при включении `rr_mode='runtime'` обязан явно проставить эти ключи, а не полагаться на UI-дефолты.
