## Cross-cutting validations

### source_event_key determinism
All keys use UUID-based discriminators (orderId, subscription.id, payment.id, jobRunId, user_id, club_id).
No ISO timestamps, no Date.now(), no Math.random().
`validateSourceEventKey()` enforces this at runtime with throw on violation.

### Runtime DDL validation in writeLedgerEntry()
Before every insert, `validateLedgerEntry()` checks:
- action_type ↔ status compatibility
- reason_code ∈ dictionary (18 values)
- target_type ∈ dictionary (9 values)
- source_subject_type ∈ dictionary (7 values)
- parent_event_key / parent_execution_key pair constraint
- chk_has_subject (≥1 subject ref NOT NULL)
- batch_start → target_type='batch' constraint
Throws on any violation — no silent fail.

### writeLedgerEntry returns execution_key
`select('id, execution_key')` after insert.
Returns `{ id, execution_key, error }` for parent propagation.

### updateLedgerPostCheck uses MERGE
Reads existing result → merges post_check → preserves access window fields.
Does NOT change status. Does NOT overwrite access_start/access_end/window_days/source_window_rule/previous_end.

### post_check key set
Fixed set: `{entitlement, telegram, subscription, ledger_row, target_resolution}`.
No `telegram_grant` key anywhere.

### post_check item schema
All items use `{applicability: 'required'|'not_applicable', status: 'pass'|'warn'|'fail'|null, details?, ref?}`.
No `applicable: boolean` anywhere.

### result contract by action_type
- grant/extend/reactivate → MUST have: access_start, access_end, window_days, source_window_rule, post_check. MAY have: previous_end.
- revoke/expire → MUST have: revoked_from, reconcile_basis, other_active_sources_checked. MAY have: previous_access_end, kept_projections.
- skip → MUST have: skip_reason. MAY have: reconcile_basis, existing_ref, other_active_sources_checked.
- failed → SHOULD have: failed_at_step, error_message.
- batch_start → post_check IS NULL.

### batch rows
No batch_start rows in current wrapped paths. N/A.

### 'completed' status
Not used in any wrapped path. Only allowed for batch_start action_type.

### 'telegram_access' as target_type
Not used anywhere. Replaced with 'club' (block 4) or 'subscription_tier' (blocks 1-3) or 'product' (grant).

### 'subscription' as target_type
Not used anywhere. Replaced with 'subscription_tier' or 'product'.
