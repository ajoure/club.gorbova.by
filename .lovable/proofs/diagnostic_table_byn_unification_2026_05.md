### Критический риск

Эвристика по любому единому порогу (`<800`, `<500`, `<300`) с большой вероятностью утроит чьи-то реальные BYN-доходы. Видны явные кластеры:
- значения 30–150 у клиентов одного и того же ученика (`6b6001fd…`, `b49a7004…`, `871ac688…`, `300cafe6…`) — это похоже на USD-ставки за обслуживание клиента.
- значения 100–200 BYN — могут быть как USD, так и реальная белорусская часовая ставка / мелкий клиент.

### Рекомендация

Авто-конверсию по порогу **не запускать**. Предлагаю один из двух безопасных путей:

**Вариант A — точечно по 3 ученикам, у которых явно USD-паттерн** (`6b6001fd…`, `b49a7004…`, `871ac688…`): сконвертировать только их строки, где `value < 200`. Таких строк ≈ 10–15 на пользователя. Risk низкий — паттерн USD у них единообразный по всем клиентам.

**Вариант B — точечно по списку user_id**, который ты пришлёшь после диалога с конкретными ученицами через Контакт-центр. Самый безопасный. UI-баннер «×3 на USD» уже стоит — новые заполнения будут корректны без миграции.

Полный CSV review-list (все 500 строк с `user_id, client_name, old_value, suggested_byn, confidence_bucket`) при необходимости выгружу отдельной командой.
