## 8. Критерий Cutover

**CUTOVER_ALLOWED = YES** если и только если:

1. S1–S12 = ALL PASS
2. R1–R3 = PASS или BLOCKED_SAFE_GUARD с формальным approval
3. R4–R18 = PASS или DEFERRED_NON_BLOCKING
4. L1–L3 = PASS или N/A
5. P1–P4 = ALL PASS
6. Нет новых FAIL фактов

**CUTOVER_ALLOWED = NO** — точный список blockers без "почти готово".
