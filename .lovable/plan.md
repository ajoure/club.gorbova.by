# PATCH v23.1.3A — ВЫПОЛНЕН

## Что сделано

### 1. Numeric input fix (priority)
- **Root cause**: начальное значение `"0"` + `onBlur` возврат к `"0"` при пустом поле → ввод `3` давал `"30"`
- **Fix**: начальное значение `""`, убран `onBlur` с нормализацией, добавлен `placeholder="0"`
- Пустое значение допустимо во время ввода, нормализация в `0` только на save

### 2. Entitlement display model
- Селектор entitlement теперь показывает человекочитаемые названия из `getProductName()` + технический код вторым слоем
- Fallback: если маппинга нет — показывается raw code как есть

### 3. Domain/section rollback
- Тип «Доступ к домену / разделу» (`email`) убран из селектора типа цели
- Причина: нет реального SoT для пользовательского domain access, `product_email_mappings` — это настройка email-отправки, не grant
- Существующие legacy email-маппинги в preview продолжают отображаться

- `src/hooks/useAccessRuleSelectors.ts`
