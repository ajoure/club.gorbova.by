3. **Синхронизация в pipeline.** Начать можно только после решения по этапам (см. вопросы). Отображение: «отправлено сообщение N» → этап, отказ → closed_lost, оплата (`orders_v2.status='paid'` по продукту ЗГ) → closed_won. Тег когорты: повтор или впервые, из тегов выше. Синхронизация только двигает этап и никогда не возвращает сделку на более ранний этап.
