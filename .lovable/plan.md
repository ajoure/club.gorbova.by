## Решение

### Шаг 1. Helper `supabase/functions/_shared/recipient-name.ts`

API:

```ts
extractFirstName(profile: { full_name?: string | null }): string | null
greetPrefix(profile): string   // "Имя, " либо "" если имя не определено надёжно
```

Логика `extractFirstName`:

1. Нет `full_name` → `null`.
2. Одно слово:
  - если оканчивается на `-ова|-ева|-ёва|-ина|-ына|-ская|-цкая|-ук|-юк|-енко|-ич|-ов|-ев|-ёв|-ин|-ын|-ский|-цкий|-ой` → `null` (это фамилия, не вставляем).
  - иначе → это слово.
3. Два+ слова:
  - перебираем токены, ищем **первый, не похожий на фамилию** по тому же regex;
  - если такой найден → возвращаем его (Title Case);
  - иначе → `null`.
4. Возвращаемое имя приводим к Title Case, режем по длине ≤ 40.

`greetPrefix` возвращает `""` если имя не определено — чтобы фраза начиналась без обращения, **а не с фамилии**.

**Никаких миграций / новых колонок в `profiles` в этом патче.**
