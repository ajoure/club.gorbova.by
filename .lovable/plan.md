# План: Proof нового контура + проверка редактирования уроков

## Диагноз

Код lesson edit dialog (AdminTrainingLessons.tsx, строки 918-947) выглядит **структурно корректным**:

- `openEditDialog` (строка 514) заполняет `formData` из lesson;
- `LessonFormContent` (строка 161) рендерит все поля с `onFormDataChange`;
- `handleUpdate` (строка 585) вызывает `updateLesson` с правильными данными;
- `updateLesson` в `useTrainingLessons.tsx` (строка 178) делает `supabase.update()` без лишних фильтров.

**Вероятная причина жалобы**: не баг в коде формы, а одно из:

1. Фокус теряется из-за re-render (хотя `memo` + `useCallback` должны это предотвращать);
2. RLS policy блокирует UPDATE молча;
3. Конкретный урок имеет проблему с данными.

Нужно **проверить фактически** через browser tools, а не гадать.
