PATCH-STAT-7: Единый визуальный каркас клубной статистики

## Проблема

Сейчас BkB и GC выглядят как два разных интерфейса:

- BkB: 2 карточки в ряду «Присутствие» (grid-cols-2)
- GC: 4 карточки в ряду «Присутствие» (grid-cols-4)
- Разный визуальный ритм, разная плотность, разное ощущение продукта

resource_mode должен влиять на **значения и доступность метрик**, но не на **структуру макета**.

## Решение: всегда 4 карточки в ряду «Присутствие»

Для **всех** клубов ряд «Присутствие» содержит ровно 4 карточки в одном grid `grid-cols-2 md:grid-cols-4`:


| Позиция | Карточка     | chat_only (BkB)    | channel_only       | chat+channel (GC) |
| ------- | ------------ | ------------------ | ------------------ | ----------------- |
| 1       | **В клубе**  | active             | active             | active            |
| 2       | **В чате**   | active (= В клубе) | disabled           | active            |
| 3       | **В канале** | disabled           | active (= В клубе) | active            |
| 4       | **Не вошли** | active             | active             | active            |


**disabled** = карточка отрисовывается, но с приглушённым стилем (opacity, dashed border) и значением «—», tooltip объясняет почему: «Канал не подключён к этому клубу».

Для **chat_only**: «В чате» показывает реальное значение = `in_chat_count` (совпадает с `in_club_total`), «В канале» — disabled.
Для **channel_only**: «В канале» = `in_channel_count`, «В чате» — disabled.

Это даёт **одинаковый визуальный каркас** для всех клубов.
