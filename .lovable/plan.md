План: закрытый импорт субтитров ЦБ20 «Конференция 5» (13.09.2026) как исторического источника

## Вывод проверки

Сейчас в проекте **нет** подходящего способа сохранить эту запись как закрытый исторический источник без урока. Проверены три существующих пути:

| Путь | Почему не подходит |
|---|---|
| Импорт субтитров курса (обычный и с проверкой) | Работает только для видео, которое стоит в уроке курса: без урока срабатывает защита «источник вне курса». Обойти её можно только созданием урока — это запрещено условием задачи. |
| Расшифровка эфира в разделе «Эфиры» | Нужно сначала привязать запись к карточке эфира и скопировать звук. Готовые субтитры этот путь не принимает. Ручная загрузка текста сразу отправляет его в ИИ за кратким итогом. Результат не попадает в корпус курса и не имеет проверки происхождения. |
| Редактор знаний | Показывает только источники из корпуса курса, у которых есть привязка к уроку и актуальный текст. |

Поэтому нужна небольшая доработка через GitHub: отдельный PR и одна управляемая миграция.

## Что построить (PR в GitHub)

**1. Схема (одна миграция, только добавления)**
- Новая таблица привязок исторических источников. Она связывает источник расшифровки с **эфиром** (запись эфира, продукт ЦБ20 20 поток, дата), а не с уроком.
  - Права: запись и чтение — только служебная роль; владелец может только читать; для остальных доступа нет.
  - Защита от повтора: уникальность по паре «источник — эфир».
- В описании источника добавить отметку «исторический, не часть урока».
- Служебная функция импорта исторических субтитров:
  - работает с правами вызывающего;
  - пустой список путей поиска;
  - запуск только служебной ролью;
  - внутри повторно использует проверенную логику текущего импорта субтитров (отпечаток субтитров, версия источника, повторный вызов не создаёт дубль);
  - вместо проверки урока проверяет привязку к эфиру.
- Существующие таблицы, функции, правила доступа и тарифы CB21 не меняются.

**2. Команда импорта (по образцу проверенного импорта субтитров)**
- Запускает только владелец (главный администратор). Есть режим пробного прогона и режим записи; пробный прогон по умолчанию.
- Из Kinescope берутся только служебные данные записи и ровно одна готовая русская дорожка субтитров. Берутся через уже защищённый способ скачивания, без ключей.
- Как однозначно определяется запись: провайдер + номер видео + эфир Kinescope + проект. Всё это должно совпасть с карточкой эфира «Конференция 5» 20 потока.
- Проверка качества субтитров (провал = остановка без записи):
  - дорожка одна, русская, статус «готово», файл целый;
  - субтитры покрывают почти всю запись, без длинных пропусков — по правилам аудита пробелов;
  - нет повторяющегося мусора;
  - длительность совпадает с записью.
  - Если найдены пропуски, запись получает статус «требует проверки», а не «готово».
- Происхождение: сохраняются версия источника, способ получения, отпечаток субтитров и отпечаток итогового текста.
- Пробный прогон выдаёт только числа и статусы: без текста, номеров и ссылок.

**3. Защита от продавца**
- Продавец по-прежнему получает только одобренные факты.
- Исторический источник не попадает в выбор по урокам CB21. Отдельный тест проверяет, что его текст не доходит до ИИ продавца.
- В редакторе знаний исторический источник можно показать только как основу для общей справки. Эту доработку лучше вынести в отдельный PR.

**4. Тесты (PGlite и модульные)**
- Права доступа и правила строк.
- Повторный вызов без дубля.
- Отказ, если: нет привязки к эфиру; дорожек несколько; субтитры изменились после пробного прогона; запись не 20 потока.
- Урок не создаётся, доступы CB21 не меняются, в продавца текст не попадает.

## Откат

- Если импорт прошёл неудачно: удалить только созданную запись источника и её привязку к эфиру, строго по отпечаткам из пробного прогона и отдельной командой. Затем проверить, что снова 59 источников.
- Схему откатывать не нужно: она только добавляет новое и ничего не ломает.

## Нужно ли решение владельца

- **Для закрытого импорта** — нет, если вы поручите выполнение отдельной командой. Текст остаётся закрытым, продавец его не видит.
- **Для фактов продавца — да, обязательно и отдельно.** Эта запись не входит в обучение CB21. Возможна только общая справка о прошлом потоке, и только после:
  - проверки текста владельцем;
  - отдельного разрешения;
  - проверки и применения в редакторе знаний.
  - Формулировки вроде «разберём» или «в курсе будет» запрещены.
- Эфир 26.08 в эту задачу не входит, пока владелец не подтвердит, что это нужная запись.
