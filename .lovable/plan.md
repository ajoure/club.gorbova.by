## Задача
На странице `cb` есть 4 кнопки в каждом тарифе:
1. Розовая «ОПЛАТИТЬ ОБУЧЕНИЕ» → `open-payment` ✔
2. Белая контурная «ЗАЯВКА НА РАССРОЧКУ» → `open-bank-installment` ✔
3. **Чёрная «ЗАЯВКА НА РАССРОЧКУ» — старая тильдовская, ничего не делает** ✖
4. Розовая «ОПЛАТИТЬ ОТ ЮРЛИЦА» → `open-invoice` ✔

Нужно заменить чёрную кнопку (#3) на нашу «ОПЛАТА В ДВА ПЛАТЕЖА» с действием `open-installment` для каждого из трёх тарифов (`buh`, `gl_buh`, `biz-l`).

## Шаги

1. **Найти HTML чёрных кнопок в `site_pages.blocks` (slug=`cb`)** — точный markup Tilda для трёх карточек тарифов.
2. **Проверить, что offer `installment` (`pay_now` c `installment_count=2` / или тип `installment`) существует у трёх тарифов** — если нет, добавить миграцией INSERT (по образцу `bank_installment`).
3. **Миграция №1 (данные тарифов)** — добавить недостающие `installment` offers для тарифов `buh`, `gl_buh`, `biz-l` (idempotent, `NOT EXISTS`).
4. **Миграция №2 (HTML `cb`)** — три `jsonb_set`-обновления: заменить HTML каждой чёрной кнопки на:
   ```html
   <a href="#" data-lovable-action="open-installment" data-tariff-key="<key>"
      class="…тильдовский класс кнопки, тот же контейнер…">ОПЛАТА В ДВА ПЛАТЕЖА</a>
   ```
   Сохранить оригинальные тильдовские классы/обёртки, чтобы не сломать сетку. Цвет — оставить чёрный (используем существующий CSS блока чёрной кнопки), только текст и `data-*` меняются.
5. **Проверка**:
   - `SELECT` regex по `blocks::text` — 3 совпадения `open-installment` для 3 tariff-key.
   - Playwright: открыть `https://cb.gorbova.by/`, скролл к тарифам, скриншот. Клик по «ОПЛАТА В ДВА ПЛАТЕЖА» → должен открыться диалог рассрочки (`open-installment` уже роутится в `SitePageBySlug.tsx`).
6. **Обновить `.lovable/plan.md`** — пометить Phase 5 «Оплата в два платежа на cb» как выполненную.

## DoD
- На `cb.gorbova.by` в каждом из 3 тарифов вместо чёрной «Заявка на рассрочку» — «ОПЛАТА В ДВА ПЛАТЕЖА».
- Клик открывает диалог рассрочки в два платежа с правильным тарифом.
- Остальные 3 кнопки продолжают работать (regression-скриншот).
- Никаких правок Tilda-разметки/сеток — только замена содержимого одной кнопки на карточку.
