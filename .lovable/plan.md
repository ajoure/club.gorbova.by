## Три задачи

### 1. Редизайн ConsentUpdateModal — убрать некрасивый блок изменений

**Проблема:** Сейчас модалка показывает summary + 3 строки "Изменено" с бейджами разного размера и иконками — выглядит неаккуратно. Упоминается "22 раздела", "14 разделов", "11 разделов" — пользователю это не нужно.

**Решение:** Полностью убрать компонент `VersionChanges` (бейджи, иконки, summary). Вместо него — краткий текст + три ссылки на документы, открывающиеся в новой вкладке:

```text
Мы обновили юридические документы. Пожалуйста, ознакомьтесь с ними:

→ Публичная оферта          (ссылка на /offer, target=_blank)
→ Политика конфиденциальности (ссылка на /privacy, target=_blank)  
→ Согласие на обработку ПД    (ссылка на /consent, target=_blank)

☑ Я ознакомлен(а) и согласен(на)...

[Выйти из системы]  [Подтвердить]
```

Чистый, единообразный дизайн. Без бейджей, без иконок "Изменено", без количества разделов.

### 2. Крестик (X) в модалке → вызывает logout

**Проблема:** Крестик не работает — `onOpenChange={() => {}}` блокирует закрытие, но сам крестик всё равно рендерится (showCloseButton по умолчанию true). Пользователь кликает — ничего не происходит.

**Решение:** Два варианта:

- **Вариант A:** Убрать крестик совсем (`showCloseButton={false}`) — пользователь использует только кнопки
- **Вариант B:** Оставить крестик, но при клике вызывать `handleLogout` — то есть крестик = "Выйти из системы"

По запросу пользователя ("крестик должен соответствовать кнопке Выйти из системы") — **Вариант B**: убираем стандартный крестик (`showCloseButton={false}`), добавляем свой кастомный крестик с `onClick={handleLogout}`.
