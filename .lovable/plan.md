

# План: Локальная унификация типографики табов в AiPageContent.tsx

## Scope

Только `src/components/ai-chat/AiPageContent.tsx`. Больше ничего не трогаем.

## Текущее состояние

- **Главные табы** (section tabs, строка 515): `text-xs`, иконки `h-4 w-4`
- **Подменю** (sub-tabs, строка 569): `text-xs`, иконки `h-3.5 w-3.5`
- Оба уровня сейчас `text-xs` — визуальная иерархия между ними отсутствует или строится только через цвет/фон

## Что делаем

### `src/components/ai-chat/AiPageContent.tsx`

1. **Главные табы** (строка 515, `sectionTabClass`): `text-xs` → `text-sm`
   - Это section-level навигация, она должна быть визуально крупнее подменю
   - Padding `px-3 py-1` оставить как есть — `text-sm` в эти рамки помещается

2. **Подменю** (строка 569): оставить `text-xs` по умолчанию
   - Подменю визуально подчинено главным табам — меньший размер оправдан
   - Менять на `text-sm` только если после п.1 runtime-проверка покажет, что разница `text-sm` vs `text-xs` выглядит нелепо или нечитаемо
   - Если текущая разница корректна — STOP-guard, подменю не трогаем

3. **Иконки подменю** (`h-3.5 w-3.5`, строка 580): не менять
   - Менять только если после п.1 баланс иконка/текст визуально нарушен, что подтверждено runtime-проверкой

## Критерии runtime-проверки

После применения п.1 проверить на:
- **Desktop** (1189px — текущий viewport пользователя): главные табы не переносятся, overflow scroll не появляется, высота tab-row не увеличилась заметно
- **640px**: табы корректно скроллятся, текст не обрезается
- **360px**: compact-режим работает, нет визуальных поломок

## STOP-guard

Если при runtime-проверке выяснится, что:
- `text-sm` на главных табах ломает layout или выглядит хуже текущего `text-xs`
- разница section vs sub-tab размеров является осознанной и уже визуально корректной

→ PATCH завершается выводом «изменения не нужны», без искусственных правок.

## Что НЕ меняем

- Embedded templates/executors content
- `tabs.tsx`, `button.tsx`, `tailwind.config.ts`, `index.html`
- Любые другие admin-страницы
- БД, RLS, edge functions

## DoD

1. Устранён реально заметный визуальный рассинхрон размеров табов в AiPageContent — главные табы визуально крупнее подменю
2. Визуальная иерархия section → sub-tab сохранена или улучшена, не уничтожена
3. Нет регрессий на desktop (1189px), 640px, 360px
4. Подменю и иконки изменены только при подтверждённой необходимости, не по умолчанию
5. Не подключены внешние зависимости, не выполнен массовый рефакторинг
