## Как работает система согласий (ревизия)

```text
┌─────────────────────────────────────────────────────┐
│  РЕГИСТРАЦИЯ (/auth, mode=signup)                   │
│                                                     │
│  Чекбокс: "Согласен с Политикой и даю согласие"     │
│  → consent_logs.insert(privacy_policy, granted=true) │
│  → profiles.update(consent_version, consent_given_at)│
└──────────────────────┬──────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────┐
│  ВХОД СУЩЕСТВУЮЩЕГО ПОЛЬЗОВАТЕЛЯ                     │
│                                                     │
│  useConsent → сравнивает:                           │
│    profiles.consent_version vs                      │
│    privacy_policy_versions.version (is_current=true) │
│                                                     │
│  Если !== → needsConsentUpdate = true               │
│           → ConsentUpdateModal (блокирующий)         │
│           → показывает changes[] из версии          │
│           → кнопка "Подтвердить" или "Выйти"        │
│                                                     │
│  Подтвердить:                                       │
│  → consent_logs.insert(privacy_policy, source=modal) │
│  → profiles.update(consent_version)                  │
└─────────────────────────────────────────────────────┘
```

**Ключевые компоненты:**

- `useConsent.tsx` — хук: загрузка текущей версии, проверка `needsConsentUpdate`, мутации grant/revoke
- `ConsentUpdateModal.tsx` — блокирующее модальное окно при смене версии
- `Auth.tsx` — чекбокс согласия при регистрации, запись в `consent_logs`
- `settings/Consents.tsx` — страница управления согласиями в ЛК
- `privacy_policy_versions` — таблица версий (version, is_current, changes[])
- `consent_logs` — лог всех действий (grant/revoke)
- `profiles.consent_version` / `consent_given_at` — текущее состояние согласия пользователя

**Триггер повторного согласия:** обновление `CURRENT_POLICY_VERSION` + новая запись в `privacy_policy_versions` с `is_current=true` → все пользователи со старой версией увидят `ConsentUpdateModal` при входе.
