## План: Discovery контента Gorbova Club за 2026 → годовой план идеологии + шаблон ежемесячного отчёта

### Что есть в данных (подтверждено запросами)

- `tg_chat_messages` — реальные сообщения чатов клубов:
  - **Gorbova Club** (`fa547c41…0506e`): **8 719 сообщений** за 05.01.2026–31.05.2026.
  - **Бухгалтерия как бизнес** (`4f8f9d8f…1456`): 3 396 сообщений за 02–05.2026.
- `news_content` — новости законодательства за 2026: **210 публикаций** (188 дайджестов + 22 срочных), c полями `category`, `keywords`, `ai_summary`, `effective_date`, `telegram_sent_at`.
- `live_events` / `live_event_sessions` — вебинары (Live-эфиры) с датами, темами, участниками.
- `channel_posts_archive` пуст — посты канала не реплицированы; используем `news_content` (это и есть лента канала «Горбова Club», публикуемая ботом) + `tg_chat_messages` как сигнал обсуждений.
- Шаблон `Шаблон_-_Годовой_план_…docx` — каркас с placeholders `{{package.ul.FLD-…}}` и таблицами по периодам и месяцам.

### Объём и ограничение scope

Это **discovery + генерация артефактов (DOCX)**, не фича. Никаких миграций, edge-функций, новых таблиц, изменений UI. Только read-only SQL и запись файлов в `/mnt/documents/`.

### Шаги (Diagnose → Plan → Dry run → Execute → Verify)

**1. Discovery (read-only, ~5–10 запросов)**

- Срез новостей по месяцам: `effective_date` → месяц, `category`, top-keywords, выбрать топ-тем месяца.
- Срез чата Gorbova Club по месяцам: количество сообщений, активные дни, top-обсуждаемые темы (через `to_tsvector` + n-gram по тексту, фильтр стоп-слов RU).
- Срез вебинаров за 2026 из `live_events` (дата, тема, длительность, участники) — берём как «информационные встречи».
- Сводим в JSON `/tmp/ideology_discovery_2026.json` с разбивкой по 12 месяцам:
  ```
  { "2026-01": {
      "news_top": [{title, effective_date, summary, source_url}, …],
      "webinars": [{title, date}, …],
      "chat_topics": ["изменения УСН", "НДС", "МЧД", …],
      "chat_volume": 1234
    }, … }
  ```

**2. Сборка годового плана (DOCX v2)**

- На вход — шаблон пользователя (структура глав 1–15 + календарь мероприятий в ГЛАВЕ 11 + тематические таблицы в ГЛАВАХ 5/6/8/12).
- Заполняем фактическими данными за каждый месяц 2026:
  - **ГЛАВА 11 — Годовой календарь:** в каждый месяц подставляем 1–2 ключевых темы дайджеста + название проведённого вебинара + дату обсуждения в чате. Формат подтверждения — «справка о проведении информирования по теме <…>, ссылка на дайджест от <дата>».
  - **ГЛАВА 5 — Информирование работников:** расширяем рекомендуемые темы 5.3.1–5.3.6 списком top-сюжетов 2026 (НДС/УСН/МЧД, новые стандарты защиты от мошенников, изменения МВД/ФНС/Минфина и т.п. — из `news_content.keywords`).
  - **ГЛАВА 8 — Информационная безопасность:** добавляем 2–3 конкретные темы из срочных новостей `category='urgent'`.
  - **ГЛАВА 12 — Отраслевые темы:** в блок «IT, онлайн-сервисы» подкладываем темы, реально звучавшие в чате Gorbova Club.
- Сохраняем `placeholders` шаблона (`{{package.ul.FLD-…}}` и `{{field:FLD-…}}`) — они нужны для канонической генерации в продукте. Просто разворачиваем содержимое глав.
- Артефакт: `/mnt/documents/Годовой_план_идеологии_Gorbova_2026.docx`.

**3. Шаблон ежемесячного отчёта (DOCX, новый)**

- Один файл-шаблон с заглавием «Отчёт о выполнении плана идеологической работы за {{месяц}} {{год}}» и таблицами:
  1. **Информирование** — тема, источник (дайджест/срочная новость), дата, форма подтверждения, ответственный.
  2. **Обсуждения в коллективе** — сводка по активным темам месяца (берётся из `tg_chat_messages`), результат, реакции.
  3. **Вебинары и обучение** — из `live_events`: тема, дата, число участников.
  4. **Правовая работа** — какие нормативные изменения разъяснены работникам (NEW из `news_content` с `category='urgent'`).
  5. **Подтверждающие материалы** — список приложений.
- Placeholders в шаблоне используют существующие FLD (тот же стиль): `{{field:FLD-000211}}` — год, `{{package.ul.FLD-000011}}` — наименование организации, и т.п.
- Дополнительно — заполненный пример за **май 2026** на реальных данных, как образец.
- Артефакты:
  - `/mnt/documents/Шаблон_месячного_отчёта_идеологии.docx`
  - `/mnt/documents/Отчёт_идеологии_2026-05_пример.docx`

**4. Текстовая выжимка** `/mnt/documents/discovery_2026_summary.md`:

- Топ-15 тем дайджеста за год, топ-10 обсуждений в чате, перечень вебинаров, рекомендуемое распределение тем по месяцам — для пользователя как читаемый отчёт.

**5. QA артефактов (обязательно)**
По правилам skill/docx — конвертирую каждый DOCX в PDF→JPG, проверяю каждую страницу: layout, отсутствие переполнений, корректность таблиц, нет пустых разделов. Только после успешной QA выдаю `<presentation-artifact>`.

### Чего НЕ делаем

- Не меняем UI/edge-функции/миграции/RLS.
- Не трогаем `canonical-document-generate-strict`, `ai-generate-document-package`, реестр FLD, `document_templates`, `document_package_*`.
- Не публикуем шаблон в `document_templates` — это файл-артефакт, который пользователь может загрузить вручную или отдать редактору.
- Не отправляем ничего в Telegram, не модифицируем `news_content` / `tg_chat_messages`.

### Definition of Done

- `/mnt/documents/Годовой_план_идеологии_Gorbova_2026.docx` — заполненный годовой план на основе реальных данных 2026.
- `/mnt/documents/Шаблон_месячного_отчёта_идеологии.docx` — пустой шаблон с placeholders.
- `/mnt/documents/Отчёт_идеологии_2026-05_пример.docx` — заполненный пример за май 2026.

- Все DOCX прошли постраничную QA (скрин каждой страницы проверен).
- В чате — короткое подтверждение со ссылками-артефактами и таблицей «месяц → ключевые темы».
