## Контекст
Баг: в Шаге 3 «Внешний продукт» поле «Цена по коэффициентам» использует **мультипликативную** формулу `base × ∏coeff_i`. Это даёт компаундинг (100×1.1×1.5=165) и зависит от количества выбранных коэффициентов нелинейно. Клиенты ожидают **аддитивную дельту от базы**: каждый коэф применяется к base независимо → `base × (1 + Σ(coeff_i − 1))` (100 + 10 + 50 = 160). Результат коммутативен по порядку выбора.

## Что меняем (только UI/presentation, без БД и без RPC)

### 1. `src/components/lesson/blocks/ExternalProductWorkshop.tsx` (~стр. 386–390)
Заменить:
```ts
const coeffProduct = allCoeffRows.reduce((acc, r) => acc * (r.coefficient || 1), 1);
const price_by_coeff = base * coeffProduct;
```
на:
```ts
const coeffDeltaSum = allCoeffRows.reduce((acc, r) => acc + ((r.coefficient || 1) - 1), 0);
const price_by_coeff = base * (1 + coeffDeltaSum);
```
`price_by_addons` (addonsSum) и остальная логика — без изменений.

### 2. `src/components/admin/trainings/StudentProgressModal.tsx` (~стр. 435–437)
Аналогичная замена, чтобы админский просмотр прогресса студента совпадал с тем, что видит сам студент.

## Пересчёт уже заполненных ответов студентов (ключевое)

**Миграция данных НЕ требуется.** Это критично и подтверждено чтением кода:

- В `state.portfolio_pricing` (PortfolioPricingRow, стр. 69–78) сохраняются только **сырые входы**: `client_type_id`, `complexity_ids[]`, `service_id`, `responsibility_ids[]`, `current_price`, `conclusion`. **Производные `price_by_coeff` / `price_by_addons` / `diff_*` / `pct_*` в БД не хранятся** — они вычисляются `useMemo` (`computed`, стр. 372–410) при каждом рендере урока из словарей `client_types/complexity/service_levels/responsibility` и сырых ID строки.
- `StudentProgressModal` считает то же самое на лету по тем же сырым полям (стр. 342, 435–437).
- `blockProgressResolver.ts` (стр. 268) читает `state.portfolio_pricing` для проверки заполненности, но не для расчёта цены.

Следствие: после деплоя правки **все клиенты, уже прошедшие/проходящие Шаг 3, при следующем открытии урока (и в админке прогресса) увидят корректную цену автоматически — без необходимости заново выбирать тип клиента и коэффициенты, без ручной миграции, без RPC-бэкфилла.** Сохранённые ответы остаются валидными, меняется только формула рендера.
