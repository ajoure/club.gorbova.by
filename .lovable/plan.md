## Итог ревизии

- Блокирующих критических находок нет: деплой возможен после preflight ниже.
- Главное ограничение: после деплоя точный SHA можно доказать только для одной функции из четырёх (sales-runtime-worker, по статической метке). Для трёх остальных read-back даёт косвенные признаки, а не VERIFIED MATCH.
- Некритичный риск: telegram-webhook обслуживает весь входящий Telegram проекта, не только ЦБ21. Редеплой — короткое переключение без изменения логики, но делать его лучше в спокойное время.
