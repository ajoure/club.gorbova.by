## 4. Фактическая причина «ссылка недействительна»

GitHub `supabase/functions/telegram-grant-access/index.ts`:
- строка 115: `member_limit: 1`
- строка 116: `expire_date: now + 86400` (24 часа)

Причина подтверждена: ссылки, отправленные 10.08 в 05:14 и 18:03–18:05, истекли ровно через 24 часа (11.08 05:14 и 11.08 18:03–18:05). То есть это штатное поведение TTL, а не сбой доступа: сам доступ у всех 9 остаётся активным.
