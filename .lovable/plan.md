# План: Иерархические табы с подменю и цветовое оформление страницы /ai

## Что делаем

Перестраиваем навигацию на `/ai`: вместо трёх равноправных табов делаем **два главных раздела** («Gorbov AI» и «Документы»), каждый из которых раскрывает **свою линию подменю** — красивые цветные pill-кнопки в стиле iOS glass, с мягкими градиентами как на странице «Саморазвитие».

```text
┌──────────────────────────────────────────────┐
│  [ 🤖 Gorbov AI ]   [ 📄 Документы ]        │  ← главные табы (pill-bar)
├──────────────────────────────────────────────┤
│  [ 💬 Чат ]  [ 📚 Туториалы ]  [ ✏️ Промпты ]│  ← подменю Gorbov AI (цветные pills)
├──────────────────────────────────────────────┤
│                                              │
│  контент выбранного подменю                  │
│                                              │
└──────────────────────────────────────────────┘

Если выбрано «Документы»:
┌──────────────────────────────────────────────┐
│  [ 🤖 Gorbov AI ]   [ 📄 Документы ]        │
├──────────────────────────────────────────────┤
│ [Для бухгалтера] [Для руководителя]          │
│ [При проверке]   [Шаблоны]                   │  ← подменю Документы
├──────────────────────────────────────────────┤
│  контент (пока заглушки)                     │
└──────────────────────────────────────────────┘
```

## Стиль подменю

- Каждая кнопка подменю — glass-pill с **лёгким цветным градиентом** (бледный, дорогой):
  - Чат: `from-blue-500/15 to-indigo-500/10` + border `blue-400/20`
  - Туториалы: `from-purple-500/15 to-violet-500/10`
  - Промпты: `from-amber-500/15 to-orange-500/10`
  - Документы подменю: `from-emerald-500/15`, `from-rose-500/15`, `from-sky-500/15`, `from-slate-500/15`
- Активная кнопка: насыщеннее фон (`/25`) + белый shadow
- Иконка в тон градиента
- backdrop-blur, border white/20 — стекло
