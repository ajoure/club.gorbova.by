## План: финализация спринта «Конструктор сайтов — справка и документация»

### Цель

Закрыть спринт полным proof-пакетом без перекладывания ручной работы на пользователя.

### Что делаю (один финальный отчёт, без новых правок кода)

**1. Discovery без логина** — собираю всё, что можно доказать чтением файлов:

- `grep` по `src/components/admin/site-builder/**` и `src/components/site-renderer/**` — список всех английских пользовательских строк (если остались), файл за файлом
- `grep` по `helpKey=` в Site Builder — точный список экранов, где встроен HelpIcon
- `grep` по `site_builder.` в `helpTexts.ts` — полный список help-key с текстами
- Извлечение оглавления секции «Конструктор сайтов» из `Documentation.tsx` — список всех 15 подразделов с заголовками и кратким описанием каждого
- Сверка с `docs/site-builder/_audit-map.md` — таблица «функция → задокументирована да/нет»

**2. Visual proof без логина** — то, что доступно публично:

- Скриншот `/docs` (публичная страница) с раскрытой секцией «Конструктор сайтов» через `browser--navigate_to_sandbox` + `browser--act` (раскрыть accordion) + `browser--screenshot`
- Скриншоты каждого из 15 подразделов по очереди
- Скриншот опубликованной страницы сайта (любой публичный URL из `gorbova.by`) как пример рендера блоков

**3. Чек-лист ручной проверки** — короткий, для сотрудника:

- Шаг 1: открыть `/admin/site-pages` → создать черновик
- Шаг 2: добавить блок → нажать ⓘ рядом с настройкой → убедиться, что popover открывается с русским текстом и ссылкой «Подробнее в документации»
- Шаг 3: открыть `/docs#site-builder` → проверить, что секция раскрывается
- Шаг 4: опубликовать → отправить тестовую заявку → проверить `/admin/forms` и карточку контакта
- Каждый шаг с ожидаемым результатом

**4. Финальный отчёт в одном сообщении** содержит:

- Карта функций Site Builder ↔ задокументировано (таблица из audit-map)
- Полный список help-key (~57 штук) с краткими описаниями
- Список файлов с встроенным HelpIcon (точные пути + строки)
- Список переведённых строк + grep-доказательство, что английских пользовательских строк не осталось (или явный список того, что осталось и почему)
- Visual proof: скриншоты `/docs` со всеми раскрытыми подразделами + публичная страница сайта
- Короткий чек-лист ручной проверки (10 шагов, по 1 строке каждый)
- Definition of Done: что именно закрыто, что остаётся за пределами спринта

### Что НЕ делаю

- Не прошу логин повторно
- Не растягиваю на несколько сообщений — один финальный отчёт

### Ограничение, о котором честно скажу в отчёте

Скриншоты экранов под авторизацией (`/admin/site-pages` редактор, `/admin/forms`, карточка контакта, Help popover в живом редакторе) технически невозможны без сессии. Для них даю короткий чек-лист с ожидаемым результатом по каждому пункту — сотрудник пройдёт за 5 минут.
