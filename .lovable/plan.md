## План: Telegram-вкладка карточки контакта — авто-скролл и зачистка пустот

### 1. Авто-скролл к последнему сообщению при возврате на вкладку Telegram (баг)

**Проблема.** В `ContactDetailSheet.tsx` Telegram-вкладка смонтирована через `forceMount` (строка 1612), поэтому `ContactTelegramChat` не размонтируется при переключении вкладок. Условие первичного pin-to-bottom внутри `ContactTelegramChat.tsx` (строки 1085–1138) сбрасывает `didInitialScrollRef` ТОЛЬКО при смене `userId`. После первого монтирования флаг = `true` и `isNearBottom()` после ухода/возврата уже false (viewport был сброшен скрытием контейнера) → новый pin не запускается, лента застревает наверху.

**Фикс.**

- В `ContactDetailSheet.tsx` пробросить в `ContactTelegramChat` новый prop `isActive={activeTab === "telegram"}`.
- В `ContactTelegramChat.tsx`:
  - Принять `isActive?: boolean` (default true).
  - В useLayoutEffect авто-скролла добавить `isActive` в зависимости и при переходе из `false` в `true` сбрасывать `didInitialScrollRef.current = false`, затем запускать существующий sticky-loop. Так при каждом возврате на вкладку лента будет жёстко прижиматься к низу 1.5 секунды (это перекрывает дозагрузку медиа).
  - На случай когда вкладка скрыта через `data-[state=inactive]:hidden` (контейнер `display: none`) — после возврата в `requestAnimationFrame` сделать дополнительный `pinToBottom()` после первого ненулевого `clientHeight` viewport.

### 2. Скрыть кнопку «Фото TG» в шапке чата

**Проблема.** В шапке `ContactTelegramChat` (строки 1741–1758) рендерится отдельная кнопка «Фото TG», дублирующая ту, что уже есть в раскрывающейся плашке Telegram-инфо («Загрузить фото», строки 1764–1777 `ContactDetailSheet.tsx`) и в `AvatarZoomDialog`.

**Фикс.** В `ContactDetailSheet.tsx` при рендере `<ContactTelegramChat .../>` (строка 1793) передать `hidePhotoButton={true}`. Сама поддержка пропа уже есть в чате (строка 94, 272, 1741). Заголовочный блок исчезнет полностью (нет других элементов в нём), пустого места не останется.

### 3. Убрать вертикальную пустоту между «Активен/редактировать» и табами

**Проблема.** В `ContactDetailSheet.tsx`:

- Строка 1482: `<Separator className="mt-3" />`
- Строка 1463: `SheetHeader` имеет `pb-3 sm:pb-4`
- Строка 1561: `<TabsList ... my-2 sm:my-3 ...>`
- Строка 1605: ещё один `<Separator className="mx-4 sm:mx-6" />`

Сумма даёт визуально широкий пустой пояс на мобильном.

**Фикс.**

- `SheetHeader`: уменьшить нижний паддинг `pb-3 sm:pb-4` → `pb-2 sm:pb-3`.
- Убрать `<Separator className="mt-3" />` (строка 1482) — бэйджи и табы и так разделены табами.
- На контейнере с tabs (строка 1560) убрать вертикальные внешние отступы у `TabsList`: `my-2 sm:my-3` → `my-1 sm:my-1.5`.
- Удалить второй `<Separator className="mx-4 sm:mx-6" />` (строка 1605) — TabsList уже даёт визуальную границу через активный стиль.

### 4. Убрать пустоту внизу карточки (под «Enter для отправки…»)

**Проблема.** На Telegram-вкладке `TabsContent` имеет `pb-3 pt-3` (строка 1613), а сам `SheetContent` ещё добавляет `pb-[env(safe-area-inset-bottom,0px)]` (sheetShell.ts строка 21) и `!bottom-2 sm:!bottom-4` (строка 15). На мобильном без жеста-домика safe-area = 0, но `pb-3` + `bottom-2` дают видимый пустой пояс ниже подписи.

**Фикс.**

- На `TabsContent` Telegram-вкладки (строка 1613): `pb-3 pt-3` → `pb-1 pt-2`.
- В `ContactTelegramChat.tsx` композер-обёртка (строки 2042–2046): подпись `<p className="text-xs text-muted-foreground mt-1">` → убрать `mt-1`, у внешнего обёрточного div уменьшить нижний паддинг (просмотрю в правке — приведу к `pb-1`).
- На остальных вкладках (внешний скролл-контейнер, строка 1809: `pb-24`) оставить как есть — там это нужно для прокрутки длинного содержимого над клавиатурой; правки локальны для Telegram-вкладки.
