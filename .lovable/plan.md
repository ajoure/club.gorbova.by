

## План: Редизайн страницы «Продукты» + документация

### Суть задачи

Привести страницу `/admin/products-v2` к дизайну страницы «Контакты»: pill-табы, поиск, сортировка по колонкам (А→Я, Я→А), сворачиваемые группы продуктов по категориям. Без изменений БД — группировка визуальная по полю `category`.

---

### Что будет сделано

**1. Редизайн AdminProductsV2.tsx по паттерну AdminContacts**

Текущая страница — 563 строки, простая таблица. Изменения:

- **Поиск**: добавить `<Input>` с иконкой `Search` в строку действий (поиск по `name`, `code`, `description`)
- **Сортировка**: использовать существующий `useTableSort` + `SortableTableHead` для колонок: Продукт (name), Категория, Домен, Статус
- **Группировка по категориям с Collapsible**: продукты сгруппировать по `category` (Подписка, Курс, Модуль, Услуга, Цифровой продукт). Каждая группа — `Collapsible` с заголовком-категорией и счётчиком. Состояние раскрытия в `localStorage`
- **Стиль**: pill-табы уже есть (совпадают с контактами). Добавить GlassCard обёртку вместо Card. Шрифты и badge-стили как в контактах

**2. Сортировка колонок**

Reuse `useTableSort` (уже есть в проекте) + `SortableTableHead`:
- По имени (А→Я / Я→А)
- По категории
- По статусу
- По домену

**3. Collapsible-группы**

```text
▼ Курс (3)
   ├─ Ценный бухгалтер 2.0          cb20     Курс    Активен
   ├─ Подоходный налог ИП            ...      Курс    Активен
   └─ Подоходный налог с физлиц      ...      Курс    Активен

▼ Модуль (5)
   ├─ ЦБ 2.0: ПВТ                   ...      Модуль  Активен
   └─ ...

▶ Цифровой продукт (2)  ← свёрнуто
```

Сортировка работает внутри каждой группы. При поиске группы раскрываются автоматически.

**4. Документация (в виде Collapsible-секции внизу страницы)**

Добавить раздел «Справка» (Collapsible, закрыт по умолчанию) с полным описанием:

- **Продукт** (`products_v2`): код, название, slug, домен, категория, Telegram-клуб, статус. Связан с тарифами, кнопками оплаты, потоками, подписками, заказами
- **Тариф** (`tariffs`): пакет доступа к продукту. Код, название, описание, period_label, access_days, is_popular, badge. Связан с кнопками оплаты и features
- **Кнопка оплаты** (`tariff_offers`): способ покупки тарифа. Типы: pay_now, trial, preregistration. Цена, рассрочка, токенизация карты, auto-charge, reject_virtual_cards, welcome-сообщение (meta)
- **Поток** (`flows`): набор (когорта) с датами и лимитом участников
- **Связи**: Продукт → Тарифы → Кнопки оплаты → Платежи. Продукт → Подписки. Продукт → Telegram-клуб. Тариф → Features (список возможностей). Кнопки → Документы (правила генерации)
- **Настройки без связей**: `landing_config`, `payment_disclaimer_text`, `public_title`/`public_subtitle` — используются только на лендинге
