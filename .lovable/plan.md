## Раздел 8. Контекстные подсказки (новое)

### 8.1. Подход

- Единый компонент для подсказок — `**HelpTooltip**` из `src/components/help/HelpComponents.tsx` (уже есть в проекте, оборачивает Radix Tooltip, работает по hover + focus, не мешает кликам).
- Использовать `customShort` (короткая строка-подсказка прямо в месте вызова) — без расширения словаря `helpTexts`, чтобы не плодить отдельный реестр для документов.
- `**alwaysShow={true}**` — подсказки активны без глобального «режима подсказок», т.к. это первичное обучение интерфейсу.
- Тон: одна–две короткие фразы. Сначала «что делает», затем «что получится». Без терминов БД и без английского.
- Применяется и в пользовательском, и в админском режиме; формулировки разные:
  - **пользователь** — бытовым языком, без слов «шаблон», «плейсхолдер», «привязка», «scope»;
  - **админ** — допускается «шаблон», «роль», «плейсхолдер», «версия», «журнал».
- Где кнопка — это `IconButton` без подписи, подсказка обязательна. Где кнопка с текстом — подсказка добавляется, если действие неочевидно или необратимо.

### 8.3. Реализация

- Импорт: `import { HelpTooltip } from "@/components/help/HelpComponents";`
- Обёртка вокруг кнопки/контрола:
  ```tsx
  <HelpTooltip helpKey="" customShort="Привязать шаблон к пакету. Действие фиксируется в журнале." alwaysShow>
    <Button …>Привязать</Button>
  ```

- Для иконочных кнопок (`Trash2`, `Pencil`, `Download`) **обязательно** `aria-label` совпадает с подсказкой, чтобы экранные читалки получили тот же смысл.
- Не добавлять подсказки на:
  - тривиальные кнопки навигации с очевидной подписью («Назад», «Закрыть»);
  - неинтерактивные badges;
  - элементы внутри dialog'ов, где уже есть описательный заголовок.
- Подсказку держать ≤ 110 символов. Если нужна длинная — выносить в отдельный info-блок над контролом, а не в tooltip.
