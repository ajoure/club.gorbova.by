

# План: Унификация шрифтов + визуальная связь sub-tab → его под-вкладки

## Проблема

На скриншоте видно 3 строки вкладок:
1. **Главные табы** (Gorbova AI, Документы, Реквизиты) — `text-sm` ✓
2. **Подменю** (Создать документ, История, Шаблоны документов, Исполнители) — `text-xs` ← меньше
3. **Под-вкладки** (Шаблоны, Правила генерации, Журнал документов, Плейсхолдеры) — `text-sm` (из `tabs.tsx` TabsTrigger) ← больше

Строка 2 меньше строки 3 — нарушение визуальной иерархии. Нужно выровнять шрифты и визуально показать, что строка 3 принадлежит активному элементу строки 2.

## Что делаем

### 1. `src/components/ai-chat/AiPageContent.tsx` — подменю `text-xs` → `text-sm`

Строка 569: заменить `text-xs` на `text-sm`, чтобы все 3 строки были одного размера шрифта.

### 2. `src/components/ai-chat/AiPageContent.tsx` — визуальная группировка sub-tab + его контент

Когда активный sub-tab имеет вложенный контент (Шаблоны документов → под-вкладки), обернуть активную кнопку sub-tab и её под-вкладки в единый визуальный контейнер — эффект «вдавленной зоны»:

- Активный sub-tab (например, «Шаблоны документов») получает стиль «вдавленной кнопки»: `inset shadow`, убирается выпуклый `shadow-sm`, добавляется `shadow-inner`
- Под-вкладки (3-я строка) оборачиваются в контейнер с лёгким фоном и скруглёнными углами, визуально продолжающий активный sub-tab — как единая «впадина»

Реализация: строки подменю и контента (строки 558-586) модифицируются так:
```tsx
{/* Подменю + вложенные под-вкладки */}
<div className="px-1 shrink-0 space-y-1">
  <div className="flex flex-wrap gap-1.5">
    {subTabs.map((tab) => {
      const isActive = activeSubTab === tab.id;
      return (
        <button className={`... text-sm ...
          ${isActive 
            ? "shadow-inner bg-gradient-to-b ring-1 ring-inset ..." 
            : "shadow-sm hover:shadow-md ..."}
        `}>
          ...
        </button>
      );
    })}
  </div>
</div>
```

Вложенный контент (3-я строка — TabsList из embedded компонентов) получает контейнер:
```tsx
<div className="mx-1 px-3 py-2 rounded-xl bg-muted/20 border border-border/10 shadow-inner">
  {/* TabsList + кнопка "Добавить шаблон" уже рендерится здесь */}
</div>
```

Это создаст визуальный эффект: нажал «Шаблоны документов» → появилась вдавленная зона с под-вкладками внутри.

### 3. Конкретные стилевые изменения для активного sub-tab

Текущий активный стиль (строка 573-575):
```
shadow-sm shadow-white/10
```

Заменить на «вдавленный» стиль:
```
shadow-inner ring-1 ring-inset ring-border/20
```

Неактивные sub-tabs остаются с `shadow-sm` (выпуклые).

## Scope — только `AiPageContent.tsx`

Не трогаем: `tabs.tsx`, `button.tsx`, `AdminDocumentTemplates.tsx`, `AdminExecutors.tsx`, `tailwind.config.ts`, `index.html`.

## DoD

1. Все 3 строки вкладок используют одинаковый размер шрифта `text-sm`
2. Активный sub-tab визуально «вдавлен» (shadow-inner) — отличается от неактивных (shadow-sm)
3. Под-вкладки (3-я строка) обёрнуты в контейнер с фоном/border, визуально принадлежащий активному sub-tab
4. Нет регрессий на desktop 1189px
5. Standalone маршруты не затронуты
