2. Help-popover для «Универсальных полей» (главное)

Иконка ? (lucide HelpCircle) рядом с заголовком секции 7. По клику открывает Popover (shadcn) с текстом примерно следующего содержания:

«Универсальные поля — это полиморфные плейсхолдеры. Один и тот же токен в шаблоне DOCX подставляет данные того типа субъекта, который реально участвует в сделке (ФЛ / ЮЛ / ИП), без необходимости делать три отдельных шаблона.

Как работает:
{{field:FLD-000103}} → если исполнитель ФЛ — берётся ФИО; если ЮЛ — название организации; если ИП — «ИП Фамилия И.О.».

Где заполняются данные:
• Заказчик (customer.*) — Кабинет клиента → Настройки → Реквизиты, активная вкладка ФЛ / ЮЛ / ИП.
• Исполнитель (executor.*) — Админка → Реквизиты.

Когда использовать:
• Универсальные — для шаблонов, которые должны работать для любого типа плательщика (рекомендуемый путь).
• Типизированные (секции 1–6) — только если шаблон строго под один тип.

Тип плательщика (ФЛ/ЮЛ/ИП) определяется по сделке (customer_subject_type / executor_subject_type).»

Тот же компонент-помощник переиспользовать для остальных секций, у которых задан helpHtml. Для секций без helpHtml — иконка ? не показывается, остаётся только hint.

3. Рендер заголовка секции

Текущая строка-заголовок:

  <TableRow … sticky>
    {label} ({count})
  &nbsp;

Превращаем в двухстрочный заголовок:

  строка 1: «7. Универсальные поля (по типу плательщика)»  [HelpCircle ?]   (23)
  строка 2: серым, text-[11px], normal-case, не uppercase — hint

Heuristics:

- Не ломать sticky-поведение (одна TableRow по-прежнему).
- colSpan={9} остаётся.
- HelpCircle — h-3.5 w-3.5, text-muted-foreground, ml-1.5, кликабельная (Popover).
- Не использовать кастомные цвета — только semantic tokens (text-muted-foreground, bg-muted/60 и т. п.).
