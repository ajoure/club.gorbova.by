

# План: Убрать лишние точки (буллеты) перед номерами в многоуровневых списках

## Проблема

В `src/pages/Offer.tsx` подпункты (subItems) рендерятся через `<ul className="list-disc ...">`, что добавляет точку-буллет `•` перед каждым номером. Визуально получается `• 11.1.1. текст` — лишняя точка перед цифрами.

## Что изменить

**Файл:** `src/pages/Offer.tsx`, строка 22

Заменить `list-disc` на `list-none` в классах `<ul>` для subItems:

```tsx
// Было:
<ul className="list-disc list-inside ml-6 mt-2 space-y-1">

// Станет:
<ul className="list-none ml-6 mt-2 space-y-1">
```

Одна строка, одно изменение. Нумерация `11.1.1.` останется, буллет-точка перед ней исчезнет.
