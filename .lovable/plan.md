## 1. Главный блокер: DB constraint

**Факт**: `access_rules_grant_target_type_check` в БД:

```
CHECK (grant_target_type IN ('entitlement', 'club', 'email', 'product_access'))
```

Значение `'training_content'` **отсутствует**. Любой INSERT с `grant_target_type = 'training_content'` падает по constraint. Весь новый контур частичного доступа нерабочий.

**Миграция** (add-only, без удаления старых значений):

```sql
ALTER TABLE access_rules DROP CONSTRAINT IF EXISTS access_rules_grant_target_type_check;
ALTER TABLE access_rules ADD CONSTRAINT access_rules_grant_target_type_check
  CHECK (grant_target_type IN ('entitlement', 'club', 'email', 'product_access', 'training_content'));
```
