## План: Full-bleed Hero на странице «Идеологическая работа» (SITE-000018)

### Цель
Первый экран = ровно один viewport (100vh, с учётом sticky-хедера). Никакой «карточки/окна» вокруг левой колонки. «Стратегия выживания бизнеса» полностью уезжает ниже фолда.

### Что меняем (только CSS-оверрайды в `<style id="hero-fullbleed-override">` + точечные правки markup hero-секции внутри `site_pages.blocks[0].content.code`)

1. **Геометрия hero = full screen**
   - `.ir-hero-v2`: `min-height: calc(100vh - <header_h>); height: calc(100vh - <header_h>);` (header ≈ 72px, замеряем Playwright перед патчем).
   - Убираем нижние `margin/padding` секции, чтобы следующий блок начинался строго за фолдом.
   - `overflow: hidden` на hero, чтобы фото не выпирало.

2. **Левая колонка — без «окна»**
   - Удалить `background`, `border`, `border-radius`, `box-shadow`, внутренний `padding`-bg у контейнера левой колонки (тот тёмный прямоугольник с рамкой на скрине).
   - Фон левой колонки = прозрачный, текст и кнопки лежат прямо на общем hero-фоне (тот же тёмный градиент, что у правой стороны).
   - Бейдж «РЕШЕНИЕ ПОД КЛЮЧ ЗА 1 ДЕНЬ», заголовок, подзаголовок, чек-листы, CTA-кнопки — без изменений по стилю/тексту/ссылкам.

3. **Фото Катерины — поднять выше**
   - `.ir-hero-v2__person`: `object-position: right top` (вместо `right bottom`), `height: 100%`, фото без фона остаётся как сейчас (`katerina-nobg.png`).
   - Никакого fade/градиента сверху.

4. **Glass-карточка «Гарантия безопасности» — оставляем как есть**
   - Стили `.ir-hero-glass` (blur, rgba, скругление) не трогаем.
   - Только пересчитываем `bottom`-выравнивание под новую высоту hero, чтобы низ glass совпадал с низом CTA-кнопок (симметрия).

5. **Уплотнение под 100vh**
   - Если на 1280×800 контент левой колонки не влезает, уменьшаем `font-size` H1 на 1 ступень и `gap` чек-листа, сохраняя визуальную иерархию. Цвета/семейство шрифтов не меняем.

6. **Следующая секция «Стратегия выживания бизнеса»**
   - Не трогаем её содержимое. Только убеждаемся через Playwright, что на 1280×800 / 1440×900 / 1920×1080 она НЕ видна без скролла.

### Адаптив
- ≥1025px: layout как на скрине (2 колонки, glass поверх фото).
- ≤1024px: hero возвращается к `min-height: auto`, контент в одну колонку, glass — в потоке под фото. 100vh-правило применяется только к desktop.

### Метод записи в БД
1. Временно деплоим `read-site-blocks` + `apply-site-blocks-patch` (super_admin, verify_jwt).
2. Скриптом `.lovable/artifacts/patch_site018_hero_fullbleed.py` читаем `code`, точечно правим CSS/markup hero, шлём base64-чанками.
3. `UPDATE site_pages` для `id=7e672fed-13f1-4ff1-8786-71a228a0c011`.
4. Сразу удаляем обе временные функции.
5. Сохраняем before/after HTML + скриншоты в `.lovable/artifacts/`.
