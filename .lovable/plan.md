
# Исправление отображения бота-админа во вкладке «Админы»

## Проблема
Счётчик на вкладке «Админы» показывает 4 (3 человека + 1 бот), но в таблице отображаются только 3 строки. Бот `gorbovabybot` не является записью в `telegram_club_members`, поэтому фильтр `adminTelegramIds.has(member.telegram_user_id)` его не находит.

## Решение

### Файл: `src/pages/admin/TelegramClubMembers.tsx`

В секции рендера вкладки `admins`, после таблицы `filteredMembers` (или вместо пустого состояния), добавить отдельный блок для бот-админов из `adminsList`, которые **не найдены** в `members`:

1. Вычислить `botAdmins` — элементы из `adminsList`, у которых `is_bot=true` и нет соответствующей записи в `members` (по `telegram_user_id`).

2. При `activeTab === 'admins'` — после основной таблицы рендерить дополнительные строки для `botAdmins` с:
   - Иконкой бота (Bot icon)
   - Имя / username
   - Бейдж «Бот» + «Администратор»
   - Без чекбокса и без действий (бота нельзя кикнуть/выдать доступ)

Это минимальное изменение — только в рендере вкладки admins, без изменения логики фильтрации или RPC.
