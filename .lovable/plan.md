PATCH-STAT-5: Final club statistics UI unification

## Проблема

PATCH-STAT-4 расширил backend payload, но UI остался прежним: бейдж `30 + 1 = 31` ничего не объясняет пользователю. Нет карточек для присутствия в чате/канале, нет пояснений кто такие "+1", нет единой визуальной модели.

## Решение: добавить новый ряд карточек «Присутствие» в ClubQuickStats

Сейчас `ClubQuickStats` имеет 2 ряда:

- **Ряд 1:** По тарифам + Всего с доступом
- **Ряд 2:** Динамика (Новые / Не продлили / Вне системы / Нарушители)

Добавляем **Ряд 3: Присутствие** — между рядами 1 и 2.

### Карточки ряда «Присутствие» (resource-mode-aware)

**Для chat+channel клуба (GC) — 4 карточки:**


| Карточка | Значение | Подпись                        | Пример          |
| -------- | -------- | ------------------------------ | --------------- |
| В клубе  | `156`    | `155 участн. + 1 админ`        | variant=default |
| В чате   | `156`    | `из них 0 только в чате`       | variant=info    |
| В канале | `156`    | `из них 0 только в канале`     | variant=teal    |
| Не вошли | `2`      | `имеют доступ, нет в ресурсах` | variant=warning |


**Для chat_only клуба (BkB) — 2 карточки:**


| Карточка | Значение | Подпись                    | Пример          |
| -------- | -------- | -------------------------- | --------------- |
| В клубе  | `30`     | `29 участн. + 1 админ`     | variant=default |
| Не вошли | `0`      | `имеют доступ, нет в чате` | variant=warning |


Карточки «В канале» и «В чате» (отдельно) скрываются для chat_only — не показываем stale/misleading данные.

### Бейдж вкладки «В клубе» — упростить

Вместо `30 + 1 = 31` показывать просто число: `**30**` (= `in_club_total`).

Детальный breakdown (участники + админы) уже отображается в карточке «Присутствие».

### Бейдж вкладки «Админы» — оставить как есть

Показывает `admins_total` (L1023). Это другое число, не связанное с `admins_in_club`.

## Детальный UI spec

### Карточка «В клубе» (ряд Присутствие)

```
┌──────────────────────┐
│ В КЛУБЕ         👥   │
│                      │
│ 156                  │
│ 155 участн. + 1 адм. │
└──────────────────────┘
```

- `value` = `summary.in_club_total`
- `subtitle` = `{in_club_regular} участн. + {in_club_admins} адм.` (если admins > 0), иначе `участников`
- variant = `default`
- tooltip = `Всего людей физически в ресурсах клуба: {regular} обычных + {admins} админов`
- onClick → tab `in_club`

### Карточка «В чате» (только для chat+channel)

```
┌──────────────────────┐
│ В ЧАТЕ          💬   │
│                      │
│ 156                  │
│ из них 0 только чат  │
└──────────────────────┘
```

- `value` = `summary.in_chat_count`
- `subtitle` = `из них {chat_only_count} только чат`
- variant = `info`
- Показывается ТОЛЬКО если `hasChannel` (= resource_mode != chat_only)

### Карточка «В канале» (только для chat+channel)

```
┌──────────────────────┐
│ В КАНАЛЕ        📢   │
│                      │
│ 156                  │
│ из них 0 только кан. │
└──────────────────────┘
```

- `value` = `summary.in_channel_count`
- `subtitle` = `из них {channel_only_count} только канал`
- variant = `teal`
- Показывается ТОЛЬКО если `hasChat` (= resource_mode != channel_only)

### Карточка «Не вошли» (всегда)

```
┌──────────────────────┐
│ НЕ ВОШЛИ        ⏳   │
│                      │
│ 2                    │
│ имеют доступ, нет    │
│ в ресурсах           │
└──────────────────────┘
```

- `value` = `summary.bought_not_joined_count`
- `subtitle` = resource-mode-aware: `имеют доступ, нет в чате` (chat_only) / `имеют доступ, нет в ресурсах` (chat+channel)
- variant = `warning`
- onClick → tab `bought_not_joined`

### Resource-mode-aware grid

- **chat_only:** 2 карточки → `grid-cols-2`
- **channel_only:** 2 карточки → `grid-cols-2`
- **chat+channel:** 4 карточки → `grid-cols-2 md:grid-cols-4`
