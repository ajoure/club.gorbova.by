## Проблема

Канонический `Calendar` (`src/components/ui/calendar.tsx`, обёртка над `react-day-picker`) рендерит сетку из 5 или 6 строк в зависимости от того, как дни месяца ложатся на недели. Из-за этого:

- Высота popover'а и самого календаря меняется при смене месяца (видно на скринах: июнь 2025 = 6 строк, июль 2025 = 5 строк).
- Стрелки `<` / `>` навигации ездят по вертикали — приходится «целиться» в новую позицию.
- Прыгает раскладка `Все периоды` (Сделки), а также все остальные попаперы с календарём.

Это единый компонент: 18 файлов импортируют `Calendar` из `@/components/ui/calendar`, других обёрток над `DayPicker` в проекте нет (остальные импорты — только тип `DateRange`). Значит фикс в одном месте автоматически распространяется на всю систему: фильтр «Все периоды» в Сделках, попаперы дат в Подписках / Контактах / Платежах / CRM / рассылках и т.д.

## Решение

1 точечная правка в `src/components/ui/calendar.tsx`:

- Включить штатный проп `react-day-picker` **`fixedWeeks`** — сетка всегда рендерится 6×7, независимо от месяца. Это убирает прыжки высоты.
- Параллельно гарантировать `showOutsideDays = true` (уже стоит) — недостающие ячейки заполняются «outside»-днями серым цветом, как и сейчас.
- Убедиться, что `day_outside`-стиль остаётся `text-muted-foreground/50 opacity-50` (визуально читается как «не активный месяц», как у вас уже привычно).

Изменение узкое: добавляется один проп по умолчанию, остальные классы и поведение не трогаем. При желании потребитель сможет отключить — `<Calendar fixedWeeks={false} />`, но дефолт = `true`.

### Технические детали

```tsx
function Calendar({
  className,
  classNames,
  showOutsideDays = true,
  fixedWeeks = true,          // новый дефолт — стабильная высота
  locale: localeProp,
  ...props
}: CalendarProps) {
  return (
    <DayPicker
      locale={localeProp ?? ru}
      showOutsideDays={showOutsideDays}
      fixedWeeks={fixedWeeks}
      ...
    />
  );
}
```

Никакие потребители не передают `fixedWeeks` сейчас — поведение по умолчанию изменится консистентно везде.

## Файлы

- `src/components/ui/calendar.tsx` — добавить проп `fixedWeeks` со значением по умолчанию `true` и пробросить в `DayPicker`.
