# PATCH-3: /ai — симметрия сверху + растянуть чат до низа (без calc/vh)

### DoD

## 3.2 Растянуть чат до низа страницы (убрать “висящий input” и белую пустоту)

### Запрещено

- Любые `style={{ height: "calc(100vh - ...)" }}`, `h-screen`, `100vh`, `dvh` в /ai для чата.

### Требуемая flex-структура (обязательная цепочка)

Сделать layout только через flex и `min-h-0`, чтобы ScrollArea правильно скроллился, а input был снизу:

- Корневой контейнер страницы /ai:
  - `className="flex flex-col flex-1 min-h-0"` (или эквивалент, если обёртка уже flex-1)
- Блок с tabs:
  - `className="shrink-0"`
- Контент вкладки “chat” (карточка чата):
  - `className="flex flex-col flex-1 min-h-0"`
- Внутри карточки:
  - ScrollArea/сообщения: `className="flex-1 min-h-0"`
  - Input-area: `className="shrink-0"`

**Итог:** карточка чата занимает весь остаток высоты до низа страницы, input прижат к низу карточки, без пустоты ниже.

### DoD

- На /ai блок `Напиши свой вопрос...` стоит внизу карточки, ниже нет белого пространства.
- Сообщения скроллятся (ScrollArea работает), input не уезжает.
